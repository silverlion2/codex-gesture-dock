# Codex Gesture Dock 设计系统

## 设计原则

- 持续可见：展开状态下摄像头、姿态、全部六个手势和安全控制不被任务列表遮挡。
- 分层操作：实时监测留在主窗口；文件与任务操作使用独立、可调整大小的窗口。
- 先反馈后动作：手势显示识别进度、等待回中状态和最终动作结果。
- 安全显性：Windows 控制开关、审批内容、更新状态和失败原因始终使用文本，不只依赖颜色。

## 布局

- 迷你摄像头 Dock：`348 × 360`，位于当前屏幕工作区右下角；保留实时画面与全部视觉工具切换。底部玻璃控制条承载当前主操作、麦克风和设备设置；摄像头运行时默认退场，鼠标移入、键盘聚焦或设置菜单打开时恢复。文件型工具提示用户展开完整面板选择文件。
- 展开主面板：默认 `1120 × 760`、最小 `980 × 760`，采用安静的双栏指挥中心；左侧把设备/取景工具条、实时摄像头与本次坐姿数据作为主任务，右侧集中提醒设置、六手势反馈、Codex 任务与安全控制。迷你与展开边界分别记忆并限制在当前显示器工作区。
- 任务选择器：默认 `620 × 720`，最小 `520 × 560`，独立窗口位于主面板左侧或工作区内；使用分组列表与轻量分隔，避免把每个任务做成独立卡片。
- 视觉工作区：标题栏内使用“姿态 / 扫码 / 文档 / 文字 / 名片 / 隐私 / 背景 / 物体 / 图片 / 颜色”十段切换；每次只展示一个工具的结果区。“图片”内再以可换行二级切换承载像素对比、重复查找、图片优化、裁剪旋转、图片检查、图片标注、联系表、长图、调整、水印、批处理和美化。迷你状态直接提供摄像头类高频操作；智能文档和文件型工具在完整面板中完成处理、确认和导出。扫码/文档模式在最小高度窗口中把摄像头压缩到约 210 px，为结果工作台保留完整可见空间。

## 视觉基础

- 视觉方向：暖白内容面、浅矿物灰工作区与深森林绿操作色。信息优先依靠间距、对齐、字重和分隔线组织；边框只用于操作边界，阴影只用于独立浮窗。
- 标题栏持续显示“仅在本机处理 · 隐私优先”、摄像头运行状态和 Windows 控制暂停入口；这些安全状态不得只依赖颜色。
- 主要动作每个区域最多一个。实时镜头是展开面板的视觉焦点，任务、手势与提醒作为右侧上下文出现，不使用指标卡片墙。

- 背景使用浅中性色，关键状态采用高对比绿/黄/红，并始终配合文字。
- 文本与控件对比必须通过 axe/Chromium 自动检查。
- 圆角和阴影用于区分浮层与内容区，不作为唯一分组信号。
- 动画只用于加载、识别进度和状态过渡；不得阻碍操作或隐藏错误。
- 麦克风默认关闭；开启/关闭必须同时显示文字、图标与输入电平，电平变化不得成为唯一状态信号。

## 交互状态

每个异步区域必须覆盖：

- Loading：明确说明正在连接、加载模型或读取任务。
- Empty：说明为什么为空以及可执行的刷新/切换动作。
- Error：使用 `role=alert` 或可见反馈，保留重试路径。
- Success：显示动作结果、连接状态或最新文件。
- Partial：Codex App Server 或 Windows 桌面层单独失败时，另一层仍可使用并显示分层状态。
- 扫码：加载解码器、寻找码、识别成功、初始化失败都有文字状态；识别结果必须由用户主动复制。
- 文档：摄像头未启动时只禁用拍摄，照片/PDF 导入仍可用；空状态明确 PDF 最多 20 页。PDF 导入期间逐页显示“栅格化 / 增强”进度，并持续提示原文本层与批注不会保留。结果区同时提供页缩略图、自动拉正/手动拉正/整图增强状态、效果重处理、多页添加、删除、PNG/PDF 导出和当前页 OCR。边缘编辑器使用四个可拖动按钮与可见多边形；按钮必须支持方向键微调和 `Shift + 方向键` 快移。未检测到可信边缘时必须显示“整图增强”，不得伪称自动矫正。
- 扫码：摄像头未启动时保留“从图片识别”主入口，并说明本机处理与 35 MB 限制；处理中显示状态，结果标明“图片”或“摄像头”来源。无代码错误使用可恢复提示，不得自动打开识别出的 URL；只有用户明确点击复制才写剪贴板。
- QR 与条码标题下使用“扫描识别 / 生成 QR”二级切换。生成区提供文字、网址、Wi-Fi、联系人类型，左侧只显示真实 SVG 预览或明确空状态，右侧显示对应字段、尺寸、生成状态与错误；只有预览有效时才显示 SVG/PNG/复制动作。任一字段变化必须隐藏过期输出，持续说明本机处理、不自动打开网址、设备兼容性和跨设备试扫要求。
- 隐私遮盖：编辑器必须持续显示“永久遮盖”语义和遮盖数量；支持拖动画框、添加默认框、选择、撤销、删除所选、清除全部，并支持方向键移动、`Shift + 方向键` 快移、`Alt + 方向键` 调整大小。只有点击“应用遮盖”才烧录像素；取消不得改变当前页。
- OCR 敏感信息建议：只在当前扫描页 OCR 完成后显示“复核 N 处敏感信息”；点击后把建议框载入同一隐私遮盖编辑器。建议不能自动改变图像，界面必须允许调整、删除或取消，并持续提醒这是疑似结果而非完整隐私保证。
- 扫描质量：页面工作台在滤镜和导出动作之前显示原图质量卡。良好用绿色，需复核用黄色，建议重拍用红色；问题必须同时给出名称和可操作建议，并显示采样分辨率、亮度与对比度。质量判断始终标为启发式、非阻断，不得把警告隐藏在悬停提示中，也不得禁用 OCR/PNG/PDF。
- 页面方向：扫描页动作区提供文字明确的“向左旋转”和“向右旋转”，不能只显示无名称图标。旋转处理中显示同步遮盖位置的状态；完成后原有 OCR 与派生字段必须消失，页面缩略图、预览、PNG/PDF 和下一次 OCR 同时使用新方向。
- 页面排序：扫描页动作区提供文字明确的“前移一页”和“后移一页”，首尾不可用动作保持可见但禁用。移动后活动页跟随同一页面对象，缩略图立即重新编号，现有 OCR 与遮盖复核状态继续属于该页；完成消息明确说明状态随页保留。
- 多页 OCR：动作区持续显示 `OCR TXT 已识别数/总页数` 和 `OCR 未识别页 数量`；没有结果时前者禁用，全部完成时后者禁用。批次处理中显示当前未识别页序号和单页百分比，并始终提供取消；导出部分结果时消息和 TXT 占位符都明确未识别页数量。
- 可搜索 PDF：动作区持续显示 `可搜索 PDF 有效词框页数/总页数`；未覆盖全部页面时按钮保持可见但禁用，悬停说明须先补齐每页 OCR。导出中显示当前页进度并说明图片、文字层和字体只在本机处理；完成消息明确文字层来自当前逐词复核文字与原词框。整段自由编辑提示同时说明不会重排可搜索层，旋转、重处理或永久遮盖后计数必须立即回退。
- 文档级敏感导航：存在任意 OCR PII 建议时，动作区显示“下一敏感页 建议数 / 页数”。点击后严格按当前页序寻找后一张含建议的页并在末尾循环，打开同一手动隐私遮盖编辑器。该动作只载入框与定位页，不得自动应用。旋转、重处理、永久遮盖或删除页面后，总数和页数立即重算。
- 扫描文档 OCR 搜索：完成任一页 OCR 后显示最多 200 字符的 search 输入。键入时以 `aria-live` 显示下一匹配页的页号、文件名和有界摘要；无命中时按钮禁用并明示结果。“下一匹配页 N”按当前页序循环，不修改 OCR 或页面内容。
- 扫描质量导航：存在非 good 质量页时，动作区显示“下一质量问题页 N”，严格按当前页序循环定位。跳转后仍显示完整页级质量卡和建议数；导航不得改变页面、自动重处理或禁用导出。
- OCR 人工复核：当前页 OCR 文本框可编辑；未改动时提示“本机 OCR 原始文本”，改动后提示复制、结构化提取和 TXT 使用当前文本，并显示“恢复识别文本”。允许人工留空但不能让复核区消失；合并 TXT 用“人工复核后为空”区别于未运行 OCR。
- OCR 置信度复核：图像 OCR 结果有词框时，动作区显示“置信度复核 N”；独立复核面板在原图上以编号框和同序列表标出词框，选中状态双向同步。顶部固定显示平均、最低、待复核、已复核数量、50–95 阈值滑杆和“包括高分词”；默认低分/未复核优先，全部模式按阅读索引顺序每组最多 100 项并提供上一组/下一组，跨组记录保持。逐词编辑须先“记录此词”再“应用 N 项复核”，空值明确解释为删除误检。持续提示评分不是正确概率、每词 200 字符且坐标/评分不变。返回动作必须恢复原 OCR/名片/扫描页工作台。
- OCR 版面导出：存在词框时，“版面 JSON”“版面 CSV”“版面 hOCR”和“版面 ALTO”与置信度复核并列且在窄宽度自动换行；可见说明必须明确逐词修正会保留原词框和评分并同步导出，整段自由编辑或名片字段编辑不会重排词框。hOCR/ALTO 名称保留大小写以表明互操作格式。导出中全部版面按钮禁用且当前按钮显示进度，成功消息给出词框数量，尺寸缺失、零有效框和解码失败必须是可恢复错误。
- 多页 OCR 版面：扫描文档动作区持续显示“多页 JSON / CSV / hOCR / ALTO 有效页/总页”。未覆盖全部页面时保持可见但禁用，悬停说明须先补齐每页词框；页面重排后计数不变但导出顺序立即跟随。成功消息必须明确页数与格式；JSON/CSV 与 hOCR/ALTO 使用同一页级语言、词框及人工来源。
- OCR 表格辅助：与版面导出并列的“表格辅助”只在用户触发后分析词框；未找到至少 3 行重复对齐候选时，在动作区显示可关闭错误并保留其他导出。命中后使用居中的模态复核表，标题持续显示行列数、对齐等级及使用/忽略词数；每格有明确“第 N 行第 M 列”标签并可编辑，横向溢出只能在表格容器滚动。关闭按钮、Escape 和导出后状态必须可理解，关闭后焦点回到触发按钮。窄窗口标题换行、按钮纵向排列。界面必须说明只提取最大简单表格，不支持合并单元格、跨页表头、嵌套表格或字段语义。
- 文件 OCR：空状态说明最多 20 个文件及每个 PDF 的 20 页限制；批次视图显示当前文件、当前 PDF 页、总进度和每项等待/处理中/完成/失败/取消状态。成功项可切换查看、复制或单独保存 TXT；批次完成后可明确导出按原顺序合并的 TXT。单项失败不得隐藏其他结果，取消后已完成结果仍可查看。
- MRZ 复核：文件 OCR 和扫描页 OCR 的结果动作均提供“提取 MRZ”。仅完整 TD1/TD2/TD3 候选进入独立字段面板；顶部同时显示格式和校验位状态，黄色警告不得被绿色成功语义覆盖。原始 MRZ 行放在折叠区，字段可编辑；“我已对照原证件”复选框未选中时复制和导出必须禁用。界面始终显示“校验位不能证明真实性”。
- 名片 OCR：顶部以“单张名片 / 批量名片”明确切换。单张解析结果必须是可编辑字段；批量空态说明 20 张上限与逐张确认，运行态复用文件批次的顺序列表、进度、取消和失败隔离，结果区显示所选名片的独立可编辑字段。逐词复核后允许重算该条字段，手改字段不得改写 OCR 词框。按钮必须分别写明“确认并导出所选 VCF”和“确认并导出合并 VCF”，不得自动写入系统联系人。
- 票据字段：只能从当前 OCR 文本由用户主动触发；商户、日期、单据号、小计、税额、总额与币种全部可编辑，并持续显示“本机规则预填，请逐项确认”。写盘按钮必须写明“确认并导出 CSV”。
- 人脸与照片隐私：加载/检测、未检测、检测成功、元数据已检查/范围受限、应用效果和错误均有文字状态；每个自动或手动隐私框必须是可聚焦的切换按钮，显示编号、来源与启用状态。提供“添加手动隐私区”，框可指针拖动，并在聚焦后支持方向键、Shift、Alt + 方向键和 Delete；拖动不能误触启停。常见元数据卡列出字段与本机值，GPS 和序列号使用高风险视觉提示，不生成地图链接。效果和保护范围改变后重新烧录预览；有启用隐私框时按钮写明“确认并导出隐私 PNG”，零个启用框或零人脸时仍提供“导出无元数据 PNG”。界面持续警告自动检测可能漏检，导出说明只承诺不复制源元数据而不承诺画面匿名。
- 人物背景：加载/分割、应用、低覆盖率、成功和错误均有文字状态；透明预览使用可见棋盘格，模糊、纯色和自定义图片控件只在对应效果出现。自定义背景必须通过明确文件选择载入并显示当前文件名与移除按钮；未载入图片时对应效果不可选。铺满/完整、水平/垂直位置及完整显示留边颜色均有可读标签，界面说明裁切、留边、内容授权与仅留内存。人物边界与边缘柔化改变后重新合成预览，必须提供原图/效果切换；蒙版编辑状态在与照片等比例的预览上使用绿色“保留人物”和红色“移除背景”软边笔划，禁用全局效果控件，并提供画笔大小、笔数、撤销、清空、取消和应用。导出按钮写明“确认并导出 PNG”，人物覆盖率低于 1% 时不得进入导出状态。界面持续提示细发丝、透明饰物、运动边缘和手动结果都需复核。
- 物体识别：空、模型验证、模型错误、推理、无结果、成功、导出和错误状态均有文字说明；当前模型名称和内置/自定义来源始终可见。自定义模型控件必须明示 TFLite 兼容性、100 MB 上限、可信来源、仅留内存和恢复内置模型；兼容性失败不得替换当前模型。预览框与结果卡必须可聚焦切换并同步启用状态。置信度滑块持续显示百分比；JSON 和标注 PNG只能包含当前阈值内且已启用的结果，零个选中项时禁用。界面必须明示标签覆盖、误检/漏检以及禁止用于身份、安全、无障碍或自动动作的边界。
- 图片对比：空状态并列显示基准图/候选图选择与文件名，缺一时主按钮禁用。结果区以原始宽高比容器承载滑动对照或差异热图；分界必须另有原生 range 控件供键盘使用，不能只依赖拖拽。右侧集中显示相似度、差异像素、占比、原图/画布尺寸、差异包围框、三档容差和尺寸不一致警告；差异 PNG 只由明确主按钮导出。
- 批量重复查找：与“两图像素对比”使用同一图片分析二级切换，选中态使用 `aria-pressed`。空状态持续显示 2–20 张、单张 35 MB、合计 200 MB 和不操作源文件；分析时显示完成数、当前文件和取消。结果顶部显示已分析、候选对、失败数及 2/8/16 距离，下方用成对缩略图、完整文件名提示、尺寸、大小、距离和结构相似度供人工复核；SHA-256 一致使用“字节完全相同”，其他候选不得用“完全重复”。零结果与部分失败都必须可见，界面始终声明不会自动删除、移动或修改文件。
- 图片优化：作为图片分析第三个二级工作区，空状态显示输入格式/35 MB 边界、本机 Canvas 和元数据重编码语义；格式、尺寸与品质控件均有可读标签，PNG 时品质滑杆保留可见但禁用。处理中显示本机编码与取消；结果使用棋盘格预览透明区域，并同时文字展示输入/输出体积、增减比例、尺寸、格式/品质和元数据状态。体积增加不得使用成功性缩小措辞；透明转 JPEG、PNG 无损、浏览器编码差异与放大复核提示始终可见。主按钮必须写“确认并导出”，调整设置和选择其他图片不得修改源文件。

## 无障碍规范

- 表情动态面具：沿用摄像头工作区而非新建视觉外壳。模式入口使用 `ScanFace` 线性图标；三种样式用 `role=radiogroup` / `role=radio` 和文字说明表达选择，颜色仅作辅助。实时画面右下角显示加载、寻找人脸、跟踪和错误状态；面具 Canvas 对辅助技术隐藏，状态文字通过 `role=status` 提供。窄屏样式单列排列，模式栏允许横向滚动。

- 所有按钮具有可读名称；图标仅装饰时设置 `aria-hidden=true`。
- 选择状态使用 `aria-pressed`/`aria-current`，加载区使用 `aria-busy`。
- Toast 使用 status，错误使用 alert，审批和确认不可只靠颜色。
- Escape 逐层返回：确认 → 动作 → 列表 → 关闭选择器。
- 键盘可以完成与鼠标相同的任务选择和确认流程。
- 每次 UI 变更必须运行 `npm run test:a11y`，保持 0 个自动 axe violation。

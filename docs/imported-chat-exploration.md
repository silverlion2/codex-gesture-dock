## 对话与版本演进

### 1. 开源生态探索

用户：

> 探索用电脑摄像头可以做什么， 现在github上应该已经有开源的解决方案

结论：摄像头开源生态已经覆盖采集、人脸/手势/姿态识别、电脑操作触发和虚拟摄像头输出。调研覆盖 OBS、opentrack、MediaPipe、OpenCV、BatesPosture、WebGazer.js、OpenSeeFace、Kalidokit、Motion、Frigate、ZXing、Tesseract、Ultralytics YOLO、pyVHR、rPPG-Toolbox、COLMAP 和 Howdy。完整能力地图见 [open-source-camera-landscape.md](./open-source-camera-landscape.md)。

产品方向比较后，优先选择“本地桌面健康助手”：每隔几秒检查坐姿、离席和连续用屏，仅保存事件与统计，不保存视频。

### 2. 坐姿助手 MVP

用户：

> 好 先做

实现了“端正”MVP：

- React + TypeScript + Vite。
- MediaPipe Pose Landmarker 本地推理。
- 4 秒个人坐姿校准、实时评分、离席计数与趋势。
- 坐姿提醒和休息提醒。
- 本地每日汇总，不保存视频。
- GPU 不可用时回退 CPU。
- 异常退出时释放摄像头。

当时验证了构建、Lint、3 项单元测试，以及 1440×900 和 390×844 的界面布局。自动验收未擅自打开物理摄像头；真实使用仍需用户授权。

### 3. 置顶悬浮按钮（0.1.0）

用户：

> 我觉得做一个悬浮小按钮就行了，需要的时候调出来惨淡

对话将“惨淡”按上下文理解为“菜单”。产品从整页仪表板重构为 Electron 桌面悬浮组件：

- 默认显示 78×78 的无边框置顶按钮，可拖动。
- 点击后展开约 420×700 的紧凑菜单。
- 收起后监测继续运行，摄像头组件不卸载。
- Electron 使用上下文隔离、沙箱渲染和白名单 IPC。
- 仅申请视频权限，不申请麦克风权限。
- 修复折叠后隐藏界面仍能被键盘或读屏访问的问题。

验证包括单元测试、Lint、生产构建、打包态页面加载、置顶与窗口尺寸、折叠/展开交互及 Windows 便携包启动。

### 4. Codex 核心手势控制（0.2.0）

用户：

> 除了这个功能还有什么建议的？ 我要codex核心功能手势控制

在坐姿助手中增加 MediaPipe Gesture Recognizer 和 Windows 白名单快捷键桥：

| 手势 | 动作 |
| --- | --- |
| 胜利手势 | 打开快速对话 |
| 食指向上 | 开始语音输入 |
| 张开手掌 | 打开 Codex 任务选择器/菜单 |
| 竖起拇指 | 打开代码审查或确认 |
| I Love You | 切换集成终端 |
| 握拳 | 切换任务侧栏或在任务模式中关闭 |

安全边界：

- 手势稳定保持 0.85 秒才触发。
- 松手后才能再次触发。
- Electron 只接受固定白名单动作。
- 发送快捷键前确认前台窗口确实属于 Codex。
- 没有把批准权限、提交、推送、删除或直接发送消息绑定到单一手势。

当时新增 4 个防误触测试，总计 7 个测试通过；同时完成 420×700 视觉验收、包内模型/脚本检查、桥接 Dry Run 和便携包启动测试。

### 5. 已完成任务的选择与处理

用户：

> 好，如何选择不同的任务，是否能够列出已经完成的任务然后给选择，进行处理？

产品设计确定为“任务选择模式”：

1. 张开手掌保持 0.8 秒调出任务列表。
2. 通过上下手势切换任务。
3. 竖起拇指确认并进入操作菜单。
4. 可选择继续、总结、代码审查、测试修复或归档。
5. 返回和关闭均有独立手势。
6. 有副作用的操作需要二次确认。

任务分为最近、已完成、已归档三个标签。列表显示标题、项目文件夹、更新时间和状态。实现基于 Codex App Server 的 `thread/list`、`thread/turns/list` 等接口；若接口不可用，回退到 Codex 自带的 `Ctrl+G` 历史搜索。

## 当前项目结构

- `src/`：React UI、姿势与手势状态机、任务选择器和本地存储。
- `electron/`：Electron 主进程、预加载桥、Codex App Server 客户端和 Windows 快捷键白名单脚本。
- `public/models/`：本地 Pose Landmarker 与 Gesture Recognizer 模型。
- `public/wasm/`：MediaPipe Vision WebAssembly 运行时。
- `docs/`：概念图、实现截图、开源方案地图和迁移档案。
- `work/app-server-schema/`：开发时核对过的 Codex App Server JSON Schema。
- `releases/`：0.3.0 便携 EXE 和原始源码 ZIP。

## 当前已知限制与边界

- 真实摄像头体验仍需用户首次运行时授权并亲测。
- 普通二维摄像头容易受光线、遮挡和前后移动影响。
- 坐姿评分是个人校准后的启发式提醒，不是医疗建议。
- Codex 任务接口可能随本机 Codex/App Server 版本变化，因此必须保留降级入口。
- 便携 EXE 未签名。
- 正式分发前应补充项目自身许可证与完整第三方许可声明。

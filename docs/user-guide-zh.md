# Codex Gesture Dock 中文使用说明书

本文适用于 Codex Gesture Dock 0.5.x。它是一个 Windows 桌面悬浮工具：摄像头和完整手势手册常驻主面板，任务与文件在独立窗口中操作；可在 Codex 与 Windows 两套手势模式间切换。

> 本项目是非官方社区项目，与 OpenAI 没有隶属或背书关系。

## 1. 使用前准备

请确认：

- 使用 Windows 10 或 Windows 11。
- 已安装并登录 Codex Desktop。
- Codex Desktop 正在运行，主窗口标题包含 `Codex`。
- 电脑有可用摄像头。
- 第一次启动时允许 Codex Gesture Dock 使用摄像头。

Windows 桌面动作会验证 Codex 的应用身份。当前支持 Microsoft Store 的官方 `OpenAI.Codex` MSIX 包，以及具有有效 OpenAI Authenticode 签名的 Codex 桌面程序。无法验证身份时，系统会拒绝发送快捷键。

## 2. 启动应用

### 使用便携版

双击发行包中的 `Codex Gesture Dock.exe` 或 `Codex-Gesture-Dock-版本号-portable.exe`。应用不会显示传统主窗口，而是在桌面右下角出现一个置顶悬浮按钮。

portable 版不会自动更新。希望自动更新时，请从 GitHub Release 下载 `Codex-Gesture-Dock-版本号-setup.exe`，退出 portable 版后完成安装，再从开始菜单或桌面快捷方式启动。

### 使用安装版

运行 `Codex-Gesture-Dock-版本号-setup.exe`，选择安装目录并完成安装。当前发行包尚未签名，Windows SmartScreen 可能显示“未知发布者”；请只从本项目官方 GitHub Releases 下载并对照 `SHA256SUMS.txt`。

### 从源码运行

在项目目录中执行：

```powershell
npm install
npm run desktop
```

开发热更新模式：

```powershell
npm run dev:desktop
```

## 3. 第一次使用

1. 点击右下角悬浮按钮，展开主面板。
2. Windows 请求摄像头权限时选择允许。
3. 点击“开始监测”。首次监测会进行约 4 秒的个人坐姿校准。
4. 校准时保持你认为舒适、端正的正常坐姿。
5. 校准完成后，实时摄像头、姿态骨架、坐姿评分和手势识别会同时工作。

收起面板不会结束当前监测。需要完全停止摄像头会话时，展开面板并点击“结束本次”。

麦克风默认关闭。只有点击麦克风按钮后 Windows 才会请求音频权限；再次点击会立即停止音频轨道。该音频只用于显示本机输入电平，不播放、不录制、不转写。

## 4. 主面板说明

主面板分为两列：

- 左侧：实时摄像头、坐姿评分、本次时长、离席次数、趋势和提醒设置。
- 右侧：完整 6 项手势手册、Codex 两层连接状态、话筒状态和会话控制。

摄像头标题栏提供十个本机模式：

- “姿态”：显示原有坐姿、骨架与手势状态。
- “扫码”：识别 QR、Data Matrix、EAN、UPC、Code 128 等常用二维码和条码；结果可手动复制，不会保存或上传。
- “文档”：可启动摄像头后拍摄，也可直接导入 PNG、JPEG、WebP、BMP 照片或最多 20 页/35 MB 的 PDF。PDF 会由随包 PDF.js 在本机逐页转成最长边不超过 2200 像素的图像，再进入相同扫描流程；原 PDF 的可搜索文本层、表单、链接和批注不会保留，这不是原生 PDF 编辑功能。应用会在本机检测纸张边缘、拉正透视，并按“黑白文档 / 灰度 / 彩色”增强；自动边缘不准确时点击“调整边缘”，拖动四个圆点贴合纸张，或聚焦圆点后用方向键微调、按住 Shift 快移，再点击“应用边缘”。可继续添加页面、删除或切换页面；使用“前移一页/后移一页”调整当前页在最终 PDF 中的位置，页面已有 OCR、遮盖和旋转状态会随页移动，首尾无效方向会自动禁用。随后可保存单页 PNG、导出按当前顺序生成的栅格多页 PDF，或对当前矫正页执行本机 OCR。若没有检测到完整边缘，状态会显示“整图增强”，请手动调整或换用对比更明显的背景和更均匀的光线重拍。
- “扫码”：启动摄像头后可实时识别 QR、Data Matrix、EAN、UPC、Code 128 等格式；也可不启动摄像头，点击“从图片识别”选择最大 35 MB 的 PNG、JPEG、WebP 或 BMP 截图/照片。结果会标明来自图片或摄像头，可复制后继续扫描。应用不会自动打开二维码中的网址；请先检查域名和内容，避免复制或访问可疑链接。
- 需要隐藏姓名、号码或地址时，先点击“隐私遮盖”。在预览上拖动画框，或点击“添加遮盖区”；聚焦遮盖框后可用方向键移动、按住 Shift 快移、按住 Alt 调整大小。扫描页完成 OCR 后，应用也会在本机提示疑似邮箱、电话、中国大陆身份证号和通过校验的金融卡号；点击“复核 N 处敏感信息”可把建议框载入同一编辑器。建议可能误检或漏检，不会自动改变图像。逐项调整、删除或确认后点击“应用遮盖”，黑色像素才会永久写入当前扫描页，后续 PNG、PDF 和 OCR 都使用遮盖后的图像；导出前仍须目视检查每一页。
- 每页 OCR 原文、当前复核文本和敏感信息建议会随该页留在当前内存会话中；可直接修改文字，修改后复制、票据/MRZ 提取和 TXT 都使用当前文本，点击“恢复识别文本”可回到本机 OCR 原文。文字修改不会重新计算敏感信息建议的位置，使用建议遮盖前仍须对照画面。切换或前后排序后再次打开该页仍可继续复核。若旋转、重新拉正、更换滤镜或应用永久遮盖，该页旧 OCR 会清除，其他页不受影响。`OCR 未识别页 N` 会按当前顺序逐页补做尚未识别的页面，并在这一轮内复用同一个本机语言模型，避免每页重新加载；可随时取消且已完成页保留，模型会在完成或取消后释放。`OCR TXT 已识别数/总页数` 导出按当前页序合并的文本；尚未 OCR 写入“尚未执行 OCR”，人工删空的已复核页写入“人工复核后为空”，不要把部分结果当成完整转录。
- 扫描完成后先查看“原图质量”卡。应用会在本机检查像素尺寸、整体亮度、对比度、边缘清晰度和局部高光集中度，并提示分辨率偏低、偏暗、过亮、低对比、可能模糊或疑似反光。它是启发式拍摄建议，不是 OCR 准确率证明，也不会禁用 OCR 或导出；出现红色建议时优先重新对焦、稳定镜头或调整均匀照明，再逐页放大检查细小文字。
- 页面方向不正确时点击“向左旋转”或“向右旋转”。应用会在本机旋转当前栅格，并同步移动已有隐私遮盖框；重复四次会回到原方向。旋转会清除当前页旧的 OCR、敏感信息建议、票据字段和 MRZ 字段，请在最终方向确定后重新 OCR。之后再切换滤镜或调整边缘时，应用会自动恢复这个方向并重新应用遮盖。
- 当前扫描页完成 OCR 后，可点击“提取票据”预填商户、日期、单据号、小计、税额、总额和币种。它是本机规则匹配，不是税务核验；请逐项对照原票据修改，确认后再复制 JSON 或导出 CSV。
- “文字”：在完整面板可一次选择最多 20 个 PNG、JPEG、WebP 或 PDF。选择识别语言后，应用会按顺序在本机处理，并在这一批次复用同一个语言模型，避免并发占用内存或为每个文件重复加载；每个 PDF 最多 20 页、每个文件最大 35 MB。列表会分别显示等待、处理、完成、失败或取消；单个文件失败不会中断后续文件。完成后可查看、复制或保存所选结果，也可把所有成功项按原文件顺序导出为一个合并 TXT。取消批次会停止当前识别、释放模型，但保留已经完成的结果。
- 图像文件、名片或扫描页识别完成后，若结果包含文字坐标，可点击“置信度复核 N”。原图上的编号框与右侧列表会优先显示低分词；用 50–95 滑杆调整复核阈值，顶部可查看平均分、最低分和当前待复核数量。点击框或列表可定位同一词，返回后原文本和字段保持不变。置信度只是 OCR 引擎的启发式评分，高分也可能读错、低分也可能正确；请逐字对照原图。为保持界面可用，最多显示 100 个最低分词。直接读取 PDF 可搜索文本层时没有 Tesseract 坐标，不会显示这个入口。
- 同一类带坐标的图像、名片和扫描页结果还可点击“版面 JSON”或“版面 CSV”。JSON/CSV 会写出识别时的原图文件名和尺寸、词序、行分组、文字、置信度，以及从左上角起算的像素坐标和 0–1 归一化坐标；CSV 会防止以 `= + - @` 开头的识别文字被表格软件当作公式执行。它们保存的是原始识别词框，人工改过的 OCR 文本或名片字段不会重新排版。文件可能含姓名、证件号等敏感文字，请像原件一样妥善处理。直接读取 PDF 文本层时没有该入口。
- 若文件 OCR 或扫描页 OCR 包含完整证件机器可读区，可点击“提取 MRZ”。应用在本机识别 TD1（3×30）、TD2（2×36）或 TD3 护照（2×44），显示校验位是否通过、OCR 易混字符修正数、姓名行末尾填充符补齐数和无效字段；带校验位的数据行不会被猜测补齐。逐项对照原证件并修正后，勾选“我已对照原证件逐项复核”，才可复制或导出 JSON。校验位只能发现读取/录入错误，不能验证证件真伪、持有人身份或证件当前有效性；不要把结果直接用于放行、开户、合规或其他高风险决策。
- “名片”：选择名片图像后在本机识别，并预填姓名、公司、职位、电话、邮箱、网站、地址和备注。请先逐项确认或修正，再点击“确认并导出 VCF”。应用不会自动修改系统联系人。
- “隐私”：选择 PNG、JPEG、WebP 或 BMP 照片后，应用使用随包分发的本机 BlazeFace 模型检测人脸；JPEG/PNG 还会在本机检查常见 EXIF/GPS 的位置、设备、序列号、时间、作者和备注字段，WebP/BMP 会明确提示检查范围受限。黄色编号框表示会处理的人脸或手动隐私区；点击可跳过或重新启用。若漏检，点击“添加手动隐私区”，直接拖动编号框到目标位置；聚焦后可用方向键微调、Shift 快移、Alt + 方向键调整大小、Delete 删除。可选择高斯模糊、像素化或黑色遮盖，并用保护范围覆盖更多边缘。逐项目视复核后点击“确认并导出隐私 PNG”；即使没有人脸，也可点击“导出无元数据 PNG”。两种导出都会重新编码像素，不复制原照片的 EXIF、GPS、XMP、IPTC 或 ICC 数据。自动检测可能漏掉侧脸、遮挡、小人脸或画面中的姓名/地址，元数据检查也不检查隐写内容；请用手动隐私区处理所有可见敏感内容后再导出。
- “背景”：选择人物照片后，应用使用随包分发的本机 SelfieSegmenter 生成前景蒙版。可移除为透明背景、模糊原背景或替换为自选纯色，并调整人物边界和边缘柔化。若自动结果漏掉头发、衣物或饰物，点击“修正人物边缘”，用绿色“保留人物”画笔补回；若误保留背景，用红色“移除背景”画笔擦除。可调整画笔大小、撤销一笔、清空本轮修正，点击“取消”会恢复进入编辑前的修正，点击“应用修正”才重新生成当前效果。画笔只改变内存中的蒙版，不涂改原图。使用“对照原图”检查头发丝、饰物和运动边缘，确认后再导出 PNG；人物区域不足 1% 时应用会拒绝导出。
- “物体”：可先启动摄像头、对准场景并点击“识别当前画面”，也可直接选择照片。应用只分析这一次明确捕获的帧，不持续识别视频；随包分发的 EfficientDet-Lite0 可定位 80 类常见 COCO 物体。需要自己的类别时，可点击“导入 .tflite”选择最大 100 MB、带 MediaPipe ObjectDetector 元数据的可信模型；应用会先验证模型，失败时继续使用原模型。模型标签未内嵌或需要替换时，可再选择每行一个、按类别索引排列的 UTF-8 标签 TXT。文件只留本次内存，点击“恢复内置模型”或关闭工具即释放，不会复制进应用目录。可调整最低置信度，点击预览框或结果卡逐项启用/跳过，再复制当前选择的 JSON，或点击“确认并导出标注 PNG”。任何模型都可能漏检、误检或不认识训练标签之外的物体；结果不得直接用于身份、安全、无障碍或自动化判断。
- “图片”中的“两图像素对比”：分别选择基准图和候选图（PNG、JPEG、WebP 或 BMP，每张最大 35 MB），点击“开始本机对比”。“滑动对照”可用鼠标或聚焦“对照分界”后按方向键检查前后变化；“差异热图”用红/蓝标出 Pixelmatch 发现的变化，并显示相似度、差异像素、占比和最小范围。可切换严格、推荐或宽松容差；容差越宽松，轻微色彩与渲染噪声越不容易计入。大图会等比例缩小到最长边不超过 2400 像素且总计不超过 400 万像素；两图尺寸不同会按左上角对齐并补白，裁切和尺寸变化会计入结果。只有点击“导出差异 PNG”才写盘。像素相似度不能证明界面功能、语义、视觉质量或无障碍没有回归，仍须滑动复核关键区域。
- “图片”中的“批量重复查找”：一次选择 2–20 张 PNG、JPEG、WebP 或 BMP，单张最大 35 MB、合计最大 200 MB。应用会在本机逐张生成 128 位结构感知哈希和缩略图，并在可用时用 SHA-256 标记字节完全相同的文件；可用严格 2、推荐 8 或宽松 16 的最大 Hamming 距离筛选候选。每一对都必须看缩略图、文件名、尺寸和大小后自行决定后续操作；应用不会删除、移动、重命名或修改图片。轻微缩放、亮度和编码变化通常仍能匹配，但旋转、大幅裁切、拼图可能漏检，结构接近但内容不同也可能误报；它不是语义图片搜索。
- “图片”中的“图片优化”：选择一张最大 35 MB 的 PNG、JPEG、WebP 或 BMP，设置 PNG/JPEG/WebP、最长边和 JPEG/WebP 品质后点击“开始本机优化”。应用保持宽高比且不放大，输出最长边最多 8192 像素、总计最多 2400 万像素；结果页显示前后体积、增减比例、尺寸和格式。PNG 为无损编码所以品质滑杆禁用；JPEG 会把透明区域合成白色，WebP 是否可用取决于当前浏览器编码器，不支持时会要求换格式。重新编码不会复制 EXIF/GPS 等源元数据，但不是专业无损优化，体积也可能变大；请放大复核文字和透明边缘，只有“确认并导出”才写盘，源文件不会改变。
- “图片”中的“裁剪旋转”：选择一张最大 35 MB 的 PNG、JPEG、WebP 或 BMP 后，在图片上拖动或缩放裁剪框，也可聚焦选择框后用键盘微调；三分法网格帮助构图。可切换自由、1:1、4:3、3:4、16:9，或向左/向右旋转 90°；每次旋转都从原文件重新生成工作图并重置裁剪框。超大原图会限制到最长边 8192 像素且不超过 2400 万像素，并在侧栏显示安全缩放比例。选择 PNG/JPEG/WebP 和品质后先“生成裁剪预览”，检查方向、构图、文字与透明边缘，再“确认并导出”。JPEG 会把透明区域转白；新文件不会覆盖源图片或复制源元数据。
- “图片”中的“图片检查”：选择一张最大 35 MB 的 PNG、JPEG、WebP 或 BMP 后，可切换查看 64 档亮度、红、绿、蓝直方图，并复核原图尺寸/方向/宽高比、文件大小、平均亮度、亮度标准差、拉普拉斯边缘响应、近黑/近白像素与透明覆盖。超大图片只缩放分析副本到最长边 2400 像素且不超过 400 万像素，原图不会改变。完全透明像素不参与曝光统计，半透明像素仍按其 RGB 值统计；在不同背景上显示透明图片时外观可能不同。暗部/亮部截断、低对比和低边缘响应只是确定性复核信号，插画、文字、柔焦、纹理与缩放都可能影响结果。可导出 schema v1 JSON，但不要把它当作审美、对焦、真实性或无障碍结论。
- “图片”中的“图片标注”：选择一张最大 35 MB 的 PNG、JPEG、WebP 或 BMP 后，可添加矩形、箭头、编号、文字和局部模糊。指针可在图片上拖动框/箭头/模糊区或点击放置编号/文字；键盘用户可选择工具后点击“在中心添加”，再选中右侧列表项，用方向键移动 1 像素、Shift + 方向键移动 10 像素、Delete 删除。最多 100 项，可撤销、重做或清空。先点击“生成扁平预览”，放大检查模糊边缘、遮挡、箭头和文字，再“确认并导出”。导出会新建不含源元数据的扁平 PNG，源图片不会覆盖；模糊和标注已写入像素，不能从导出图中单独移除，应用也不会保存可编辑工程。
- “图片”中的“联系表”：一次选择 2–20 张 PNG、JPEG、WebP 或 BMP，单张最大 35 MB、合计最大 200 MB。左侧按当前顺序预览网格；右侧可用上/下按钮调整每张图片的位置，三张以上时可移除。可选择 2–5 列、输出宽度、方形/横向/纵向单格、“完整显示”或“居中填满”、浅/深背景、间距以及是否显示序号和文件名。“完整显示”保留整张图片但可能留白；“居中填满”会裁掉边缘，必须检查主体。超长联系表会自动缩放到最长边 8192 像素且不超过 2400 万像素，界面显示实际输出和安全比例。先“生成联系表预览”，放大复核顺序、裁切和文件名，再“确认并导出”。图片按顺序在本机逐张解码，导出是不含源元数据的扁平 PNG；源文件不会改变，布局工程不会保存。
- “图片”中的“长图”：顶部选择“拼接长图”或“拆分长图”。拼接一次选择 2–12 张图片，单张最大 35 MB、合计最大 160 MB；用上/下按钮确认顺序，选择纵向向下或横向向右、无/8/24 px 间距及白色/深色/透明背景。第一张总是完整保留；对每张后续图片可选择裁去顶部或左侧 5%–50%，用来手动去掉滚动截图的重叠开头。这个比例不是自动识别结果，必须先生成预览并放大检查接缝、文字和主体。拼接以最小宽度或高度统一图片，不会放大小图。拆分选择一张最大 35 MB 的长图，设置纵向/横向和 2–12 份；边界连续，不会跳过或重复源像素。结果页可逐份导出或请求导出全部，后者可能触发浏览器的多文件下载确认。解码后超过 8000 万像素的源图会被拒绝；每个 PNG 受 8192 边长/2400 万像素限制，不复制 EXIF/GPS、不改写源文件、不保存工程。
- “图片”中的“调整”：选择一张最大 35 MB 的 PNG、JPEG、WebP 或 BMP，可先选中性、鲜明、暖调、冷调、黑白或褪色预设，再用滑杆微调曝光（-2 至 +2 EV）、对比度、饱和度、色温和灰度。处理顺序固定为曝光→对比度→色温→饱和度→灰度，因此相同设置会得到确定结果；它不是 RAW 显影或专业色彩管理。点击“生成调整预览”后，用“对照分界”滑杆或键盘检查主体、文字、肤色、高光和暗部。设置变化会要求重新生成预览。选择 PNG/JPEG/WebP 与品质后点击“确认并导出”；JPEG 会把透明区域转为白色。预览最多 1600 边/240 万像素，最终输出最多 8192 边/2400 万像素；源图超过 8000 万解码像素会被拒绝。新文件不覆盖源图片，也不复制 EXIF/GPS。
- “图片”中的“水印”：一次选择 1–12 张 PNG、JPEG、WebP 或 BMP，单张最大 35 MB、合计最大 160 MB；列表顺序就是后续逐张处理顺序，可上移、下移或移除。选择 1–80 字符文字，或最大 10 MB 的 PNG/JPEG/WebP Logo；可设置九宫格位置或全图平铺、不透明度、尺寸、边距和旋转，文字还可选黑/白并自动加反色描边。先点击“生成首图预览”，再用前后分界检查遮挡、可读性、透明边缘与位置；任何水印设置变化都会要求重新预览。选择 PNG/JPEG/WebP 和品质后点击“确认并导出 N 张”，应用按顺序逐张生成，浏览器可能要求允许多文件下载；取消或后续文件失败时，此前已请求的下载不会撤回。每个结果最多 8192 边/2400 万像素，JPEG 透明区域转白，不覆盖源图片或复制 EXIF/GPS。可见水印仍可被裁剪、涂抹或重制，不是隐形水印、密码学签名或内容来源认证。
- “图片”中的“批处理”：一次选择 1–20 张 PNG、JPEG、WebP 或 BMP，单张最大 35 MB、合计最大 200 MB；用上移、下移和移除确认处理顺序。选择保留原尺寸或最长边 3200/2048/1600/1080/640 像素，输出 PNG/JPEG/WebP，并设置品质；小图不会被放大。重命名可选“原名 + 编号”或“仅编号”，再填写安全前后缀和起始编号；界面会逐项显示预计输出名，三位顺序号避免同名覆盖。先生成首图预览并滑动检查细节、透明边缘和 JPEG 白底，设置或顺序变化后必须重新预览；确认后逐张下载，浏览器可能要求允许多文件下载。重新编码不复制 EXIF/GPS，也不覆盖源图片。
- “颜色”：选择 PNG、JPEG、WebP 或 BMP（最大 35 MB）后，应用在本机提取最多 6 个去重后的 OKLCH 代表色。先选择“取样文字色”或“取样背景色”，再点击图片或代表色色块；也可用颜色选择器或六位 HEX 手工调整、交换两色。右侧显示 WCAG 2 对比比率，以及 AA/AAA 正文与大字的通过状态；可复制 CSS 变量或 JSON，不会自动写盘。透明像素按白色合成，大图会缩小到最长边 2400 像素且总计不超过 400 万像素。这个结果只判断当前两个纯色，不能确认图片中文字的位置、字号、描边或整个设计已经无障碍。

取景画面左上角可切换“镜像 / 原图”。镜头上方的设备工具条可选择摄像头、麦克风以及“填满 / 完整”取景；切换正在使用的摄像头会自动重启本次校准。选择镜像时文档输出也会保持镜像方向；扫描器始终从原始视频帧识别，不受预览方向影响。扫码和文档模式会暂停主界面的手势推理，回到姿态模式后恢复。文字、名片、隐私、背景、物体、图片和颜色模式可直接使用文件；折叠状态会提示展开完整面板后继续。

迷你 Dock 中，摄像头待命时底部控制条持续可见；运行后控制条会退场，把更多空间留给画面。把鼠标移入 Dock、用 Tab 聚焦控制项或打开设备菜单即可重新显示。迷你与展开窗口的位置/尺寸会分别记忆。

顶部按钮：

- 任务列表图标：打开独立的“文件与任务”窗口。
- 向下箭头：收起主面板，保留悬浮按钮。
- `×`：退出 Codex Gesture Dock。

提醒设置：

- “坐姿提醒”：可关闭，并可选择温和、中等或严格灵敏度。
- “休息提醒”：可选择 30、45、50 或 60 分钟。
- “Codex / Windows 手势”：开关可暂停识别；右侧下拉框切换控制模式，手势手册会立即显示所选模式的全部 6 项动作。选择会在本机保存。

## 5. 两套主界面手势

手势需要稳定保持约 0.85 秒。触发后先松手，等待状态显示“等待手势”，再做下一个动作。

### Codex 模式

| 手势 | 动作 | 作用方式 |
| --- | --- | --- |
| ✌ 胜利手势 | 打开快速对话 | 验证后的 Codex 快捷键 |
| ☝ 食指向上 | 激活 Codex 话筒 | 验证后的 Codex 快捷键 |
| ✋ 张开手掌 | 打开文件与任务窗口 | Dock 本机窗口 |
| 👍 竖起拇指 | 打开代码审查 | 验证后的 Codex 快捷键 |
| 🤟 I Love You | 切换集成终端 | 验证后的 Codex 快捷键 |
| ✊ 握拳 | 切换任务侧栏 | 验证后的 Codex 快捷键 |

“激活 Codex 话筒”是向 Codex Desktop 发送听写快捷键，与 Dock 自己的麦克风电平开关互相独立。Dock 只在用户点击“打开麦克风”后申请音频权限。

### Windows 模式

| 手势 | 动作 | 固定系统键 |
| --- | --- | --- |
| ✌ 胜利手势 | 打开任务视图 | `Win + Tab` |
| ☝ 食指向上 | 提高系统音量 | 音量增大键 |
| ✋ 张开手掌 | 显示桌面 | `Win + D` |
| 👍 竖起拇指 | 打开文件资源管理器 | `Win + E` |
| 🤟 I Love You | 降低系统音量 | 音量减小键 |
| ✊ 握拳 | 静音 / 恢复声音 | 静音键 |

Windows 模式不要求 Codex 窗口位于前台，但只允许表中 6 个动作。它不能点击任意位置、输入文字、关闭程序、关机或删除文件。

文件与任务窗口打开后，其上下文手势优先于当前模式；审批卡片出现时，👍 / ✌ 也始终优先执行仅允许本次 / 拒绝。关闭上下文窗口后才恢复所选的 Codex 或 Windows 映射。

## 6. 文件与任务窗口

点击主面板顶部的任务图标即可打开独立窗口。在 Codex 模式下也可保持 ✋ 张开手掌；Windows 模式的 ✋ 用于显示桌面。主摄像头和手势手册仍留在原来的主面板中，不会被任务窗口遮住。

### 未查看文件

当刚完成的 Codex 任务产生新增、修改或生成文件时，“未查看文件”标签会优先显示这些文件。

- 点击文件主体：使用系统默认程序打开文件。
- 点击文件夹图标：在 Windows 文件资源管理器中定位文件。
- 成功打开后，文件会标记为“已查看”。
- 已删除的文件会打开原所在目录。
- 如果列表为空，表示最近没有新文件，或所有文件已经查看。

文件列表只接受 Codex App Server 返回并由主进程换成临时 ID 的路径，界面不能直接提交任意本机路径。

### Codex 任务

任务可以按以下分类查看：

- 最近
- 已完成
- 已归档

选择任务后可以执行：

| 操作 | 说明 |
| --- | --- |
| 打开查看 | 在 Codex Desktop 中打开该任务 |
| 继续处理 | 检查未完成项并继续推进 |
| 总结状态 | 只读总结完成项、风险和下一步 |
| 审查改动 | 只读检查正确性、风险和测试 |
| 测试并修复 | 运行相关测试并修复失败 |
| 归档任务 | 把任务从最近列表移到归档 |

除直接查看外，任务操作会进入确认页。请核对任务与操作名称后再点击“确认执行”。

### 文件与任务窗口中的手势

| 手势 | 列表中的作用 |
| --- | --- |
| ☝ 食指向上 | 选择上一项 |
| ✊ 握拳 | 选择下一项 |
| 👍 竖起拇指 | 打开、选择或确认 |
| ✌ 胜利手势 | 返回上一步或关闭窗口 |

## 7. Codex 审批

当由 Dock 发起的 Codex 回合请求执行命令或修改文件时，主面板会自动展开并显示审批卡片。

- “仅允许本次”：只批准当前这一项请求。
- “拒绝”：拒绝当前请求。
- 👍 竖起拇指：仅允许本次。
- ✌ 胜利手势：拒绝。

批准前请阅读显示的命令、文件操作和工作目录。系统不会通过手势授予整次会话的持续权限。

Dock 使用独立 App Server 连接，因此不能接管另一个 Codex 客户端已经持有的审批弹窗。Codex Desktop 自己发起的审批仍需在 Codex Desktop 中处理。

## 8. 两层连接状态

主面板的 `CODEX LINK` 区域会显示：

- `Codex Adapter`：App Server 是否连接。它负责任务、文件、回合、事件和审批。
- `Windows Core`：Codex 桌面窗口与应用身份是否验证成功。
- `UIA 只读`：是否完成脱敏的 Windows UI Automation 结构检查。
- `Window Events`：是否正在实时监听已验证 Codex 进程的窗口事件。

`TWO-LAYER ONLINE` 表示 Codex Adapter 已连接；Windows Core、UIA 和 Window Events 各自显示独立状态，便于判断具体问题。

## 9. 暂停 Windows 控制

点击 `CODEX LINK` 区域中的“暂停 Windows 控制”，可以立即阻止所有 Codex 快捷键和 Windows 系统动作。暂停状态会保存，重新启动 Dock 后仍然有效。

暂停后：

- 快速对话、Codex 话筒、代码审查、终端和侧栏等 Windows 动作会被拒绝。
- 显示桌面、任务视图、资源管理器和音量动作也会被拒绝。
- 文件与任务窗口、App Server 任务读取、文件打开和审批功能仍可继续使用。
- 点击“恢复 Windows 控制”后，桌面动作重新启用。

如果怀疑手势误触、窗口焦点异常或 Codex 身份验证异常，请先暂停 Windows 控制。

## 10. 摄像头与隐私

- 摄像头画面、人体关键点和手势识别都在本机处理。
- 默认不录制或上传图像、视频和人体关键点。文档模式只在用户主动拍摄并点击保存后写入一张 PNG；应用不会上传该文件。
- QR 和条码结果只在当前界面内存中显示，除非用户主动复制，否则不会写入剪贴板或本机存储。
- Dock 只在用户明确开启麦克风后读取音频；只计算本机输入电平，不播放、录制、转写或上传。
- `localStorage` 保存按天累计的坐姿统计、已查看文件标记以及所选媒体设备/取景偏好；其中不包含媒体内容。
- Windows 控制审计不记录任务正文、窗口文本、按键内容或摄像头数据。

Windows 控制审计日志位于：

```text
%APPDATA%\codex-gesture-dock\audit\windows-control-YYYY-MM-DD.jsonl
```

日志只记录时间、动作名、目标进程、执行结果、急停状态和身份验证状态。

## 11. 常见问题

### 看不到摄像头画面

1. 打开 Windows“设置 → 隐私和安全性 → 相机”。
2. 允许桌面应用访问摄像头。
3. 关闭占用摄像头的其他程序后重试。
4. 在 Dock 中结束本次监测，再点击“再次开始”。

### 手势没有触发

- 确认“Codex / Windows 手势”开关已打开，并检查下拉框是否选中了需要的模式。
- 让整只手处于画面中，并改善正面光线。
- 手势稳定保持 0.85 秒，不要快速挥动。
- 每次触发后完全松手，再做下一个手势。
- 如果 `Windows Core` 显示已暂停，先点击“恢复 Windows 控制”。

### Codex Adapter 一直显示未连接

- 确认 Codex Desktop 已安装、已登录并正在运行。
- 等待几秒让 Dock 自动发现最新的 Codex Desktop App Server 运行时。
- 退出并重新打开 Codex Gesture Dock。
- 更新到较新的 Codex Desktop 版本。

### Windows Core 显示未就绪

- 打开 Codex Desktop 主窗口。
- 确认使用官方 `OpenAI.Codex` Microsoft Store 包或有效 OpenAI 签名版本。
- 不要使用标题伪装为 Codex 的浏览器或第三方程序。
- 如果刚更新 Codex，完全退出 Codex Desktop 后重新打开。

### UIA 显示待检查，但快捷键可用

UIA 只用于只读结构诊断。当前 Codex WebView 没有暴露稳定的业务控件，桌面动作使用经过身份和前台验证的固定快捷键后端。UIA 暂时不可用不一定影响这些快捷键动作。

### 没有看到刚完成的文件

- 点击“未查看文件”页底部的刷新按钮，或使用 🤟 手势。
- 确认对应 Codex 回合已经完成。
- 已打开过的文件会被记为已查看，不再出现在未查看列表。
- 切换到“Codex 任务”确认任务状态是否为已完成。

### 动作发送到了错误窗口吗

Codex 模式的每个桌面动作执行前都会验证 Codex MSIX/签名身份、目标进程、窗口和最终前台进程；任一检查失败都会取消动作。Windows 模式只发送固定系统组合键，不会把文本发送给前台程序。发现异常时仍应立即使用“暂停 Windows 控制”。

## 12. 键盘、辅助技术与界面恢复

- 使用 `Tab` / `Shift+Tab` 在按钮、开关、筛选和下拉框之间移动，按 `Enter` 或空格激活。
- 在文件与任务窗口中按 `Esc`：确认页返回操作页，操作页返回列表，列表页关闭窗口。
- 当前页签、任务筛选和手势/Windows 控制状态会通过辅助技术可读的状态属性表达，不只依赖颜色。
- Windows 开启“减少动画”后，Dock 会停用非必要动画和过渡。
- 如果 React 界面发生未捕获错误，会显示不含任务正文或本机路径的恢复页；点击“重新加载”恢复。
- Electron renderer 崩溃或持续无响应时会限次自动重载。任务窗口连续失败会单独关闭，不影响主面板；主面板连续失败会明确提示并退出，避免无限重启。

## 13. 退出、自动更新与清理

- 退出：展开主面板并点击右上角 `×`。
- 安装版：启动后约 15 秒自动检查更新，之后每 6 小时检查一次。发现新版本会在后台下载；下载完成后点击 `CODEX LINK` 区域的“重启安装”并再次确认。
- 如果暂不重启，已下载的更新会在之后退出应用时安装。
- 可随时点击 `CODEX LINK` 区域中的“检查更新”。
- portable 版：退出旧版本后，用新版文件替换旧版并重新启动。
- 删除应用：退出后删除便携版程序或解压目录。
- 如需同时清除本机设置、任务绑定和审计日志，可在应用完全退出后删除 `%APPDATA%\codex-gesture-dock`。删除前请确认不再需要其中的审计记录。

## 14. 功能边界

当前 v1 已完成 Codex 两层闭环和 6 项常用 Windows 系统手势，但不会提供以下危险能力：

- 任意 Windows 程序控制
- 任意键盘文字输入
- 任意命令或脚本执行入口
- 任意窗口句柄或 UIA 选择器
- 坐标点击
- 密码框、对话正文或编辑框内容读取

新程序必须增加独立 Adapter、应用身份策略、动作白名单和测试，不能通过现有接口直接获得通用桌面控制权。

自动更新地址固定为本项目 GitHub Releases，界面和手势不能指定其他下载地址。当前未配置 Authenticode 证书，因此自动更新具备版本检查、哈希元数据与用户确认，但 Windows 仍可能显示未知发布者警告；可信静默更新需要后续配置发布证书。

更多技术边界见 [Windows 桌面控制设计](windows-desktop-control.md)。

# Codex Gesture Dock 中文使用说明书

本文适用于 Codex Gesture Dock 0.5.x。它是一个 Windows 桌面悬浮工具：摄像头和完整手势手册常驻主面板，任务与文件在独立窗口中操作；可在 Codex 与 Windows 两套手势模式间切换。

> 本项目是非官方社区项目，与 OpenAI 没有隶属或背书关系。

## 1. 使用前准备

请确认：

- 使用 Windows 10 或 Windows 11。
- 已安装并登录 Codex Desktop。
- Codex Desktop 正在运行，主窗口标题包含 `Codex`。
- 电脑有可用摄像头。
- 第一次启动时允许 Codex Gesture Dock 使用摄像头。

Windows 桌面动作会验证 Codex 的应用身份。当前支持 Microsoft Store 的官方 `OpenAI.Codex` MSIX 包，以及具有有效 OpenAI Authenticode 签名的 Codex 桌面程序。无法验证身份时，系统会拒绝发送快捷键。

## 2. 启动应用

### 使用便携版

双击发行包中的 `Codex Gesture Dock.exe` 或 `Codex-Gesture-Dock-版本号-portable.exe`。应用不会显示传统主窗口，而是在桌面右下角出现一个置顶悬浮按钮。

portable 版不会自动更新。希望自动更新时，请从 GitHub Release 下载 `Codex-Gesture-Dock-版本号-setup.exe`，退出 portable 版后完成安装，再从开始菜单或桌面快捷方式启动。

### 使用安装版

运行 `Codex-Gesture-Dock-版本号-setup.exe`，选择安装目录并完成安装。当前发行包尚未签名，Windows SmartScreen 可能显示“未知发布者”；请只从本项目官方 GitHub Releases 下载并对照 `SHA256SUMS.txt`。

### 从源码运行

在项目目录中执行：

```powershell
npm install
npm run desktop
```

开发热更新模式：

```powershell
npm run dev:desktop
```

## 3. 第一次使用

1. 点击右下角悬浮按钮，展开主面板。
2. Windows 请求摄像头权限时选择允许。
3. 点击“开始监测”。首次监测会进行约 4 秒的个人坐姿校准。
4. 校准时保持你认为舒适、端正的正常坐姿。
5. 校准完成后，实时摄像头、姿态骨架、坐姿评分和手势识别会同时工作。

收起面板不会结束当前监测。需要完全停止摄像头会话时，展开面板并点击“结束本次”。

麦克风默认关闭。只有点击麦克风按钮后 Windows 才会请求音频权限；再次点击会立即停止音频轨道。该音频只用于显示本机输入电平，不播放、不录制、不转写。

## 4. 主面板说明

主面板分为两列：

- 左侧：实时摄像头、坐姿评分、本次时长、离席次数、趋势和提醒设置。
- 右侧：完整 6 项手势手册、Codex 两层连接状态、话筒状态和会话控制。

摄像头标题栏提供五个本机工具：

- “姿态”：显示原有坐姿、骨架与手势状态。
- “扫码”：识别 QR、Data Matrix、EAN、UPC、Code 128 等常用二维码和条码；结果可手动复制，不会保存或上传。
- “文档”：对齐取景框后拍摄当前帧，先在内存中预览；点击“保存 PNG”后才写入下载目录。
- “文字”：在完整面板选择 PNG、JPEG、WebP 或 PDF，选择识别语言后在本机提取文字。PDF 最多 20 页，文件最大 35 MB；结果可复制或明确保存为 TXT。
- “名片”：选择名片图像后在本机识别，并预填姓名、公司、职位、电话、邮箱、网站、地址和备注。请先逐项确认或修正，再点击“确认并导出 VCF”。应用不会自动修改系统联系人。

取景画面左上角可切换“镜像 / 原图”。镜头上方的设备工具条可选择摄像头、麦克风以及“填满 / 完整”取景；切换正在使用的摄像头会自动重启本次校准。选择镜像时文档输出也会保持镜像方向；扫描器始终从原始视频帧识别，不受预览方向影响。扫码和文档模式会暂停主界面的手势推理，回到姿态模式后恢复。文字和名片模式不需要启动摄像头；折叠状态会提示展开完整面板后选择文件。

迷你 Dock 中，摄像头待命时底部控制条持续可见；运行后控制条会退场，把更多空间留给画面。把鼠标移入 Dock、用 Tab 聚焦控制项或打开设备菜单即可重新显示。迷你与展开窗口的位置/尺寸会分别记忆。

顶部按钮：

- 任务列表图标：打开独立的“文件与任务”窗口。
- 向下箭头：收起主面板，保留悬浮按钮。
- `×`：退出 Codex Gesture Dock。

提醒设置：

- “坐姿提醒”：可关闭，并可选择温和、中等或严格灵敏度。
- “休息提醒”：可选择 30、45、50 或 60 分钟。
- “Codex / Windows 手势”：开关可暂停识别；右侧下拉框切换控制模式，手势手册会立即显示所选模式的全部 6 项动作。选择会在本机保存。

## 5. 两套主界面手势

手势需要稳定保持约 0.85 秒。触发后先松手，等待状态显示“等待手势”，再做下一个动作。

### Codex 模式

| 手势 | 动作 | 作用方式 |
| --- | --- | --- |
| ✌ 胜利手势 | 打开快速对话 | 验证后的 Codex 快捷键 |
| ☝ 食指向上 | 激活 Codex 话筒 | 验证后的 Codex 快捷键 |
| ✋ 张开手掌 | 打开文件与任务窗口 | Dock 本机窗口 |
| 👍 竖起拇指 | 打开代码审查 | 验证后的 Codex 快捷键 |
| 🤟 I Love You | 切换集成终端 | 验证后的 Codex 快捷键 |
| ✊ 握拳 | 切换任务侧栏 | 验证后的 Codex 快捷键 |

“激活 Codex 话筒”是向 Codex Desktop 发送听写快捷键，与 Dock 自己的麦克风电平开关互相独立。Dock 只在用户点击“打开麦克风”后申请音频权限。

### Windows 模式

| 手势 | 动作 | 固定系统键 |
| --- | --- | --- |
| ✌ 胜利手势 | 打开任务视图 | `Win + Tab` |
| ☝ 食指向上 | 提高系统音量 | 音量增大键 |
| ✋ 张开手掌 | 显示桌面 | `Win + D` |
| 👍 竖起拇指 | 打开文件资源管理器 | `Win + E` |
| 🤟 I Love You | 降低系统音量 | 音量减小键 |
| ✊ 握拳 | 静音 / 恢复声音 | 静音键 |

Windows 模式不要求 Codex 窗口位于前台，但只允许表中 6 个动作。它不能点击任意位置、输入文字、关闭程序、关机或删除文件。

文件与任务窗口打开后，其上下文手势优先于当前模式；审批卡片出现时，👍 / ✌ 也始终优先执行仅允许本次 / 拒绝。关闭上下文窗口后才恢复所选的 Codex 或 Windows 映射。

## 6. 文件与任务窗口

点击主面板顶部的任务图标即可打开独立窗口。在 Codex 模式下也可保持 ✋ 张开手掌；Windows 模式的 ✋ 用于显示桌面。主摄像头和手势手册仍留在原来的主面板中，不会被任务窗口遮住。

### 未查看文件

当刚完成的 Codex 任务产生新增、修改或生成文件时，“未查看文件”标签会优先显示这些文件。

- 点击文件主体：使用系统默认程序打开文件。
- 点击文件夹图标：在 Windows 文件资源管理器中定位文件。
- 成功打开后，文件会标记为“已查看”。
- 已删除的文件会打开原所在目录。
- 如果列表为空，表示最近没有新文件，或所有文件已经查看。

文件列表只接受 Codex App Server 返回并由主进程换成临时 ID 的路径，界面不能直接提交任意本机路径。

### Codex 任务

任务可以按以下分类查看：

- 最近
- 已完成
- 已归档

选择任务后可以执行：

| 操作 | 说明 |
| --- | --- |
| 打开查看 | 在 Codex Desktop 中打开该任务 |
| 继续处理 | 检查未完成项并继续推进 |
| 总结状态 | 只读总结完成项、风险和下一步 |
| 审查改动 | 只读检查正确性、风险和测试 |
| 测试并修复 | 运行相关测试并修复失败 |
| 归档任务 | 把任务从最近列表移到归档 |

除直接查看外，任务操作会进入确认页。请核对任务与操作名称后再点击“确认执行”。

### 文件与任务窗口中的手势

| 手势 | 列表中的作用 |
| --- | --- |
| ☝ 食指向上 | 选择上一项 |
| ✊ 握拳 | 选择下一项 |
| 👍 竖起拇指 | 打开、选择或确认 |
| ✌ 胜利手势 | 返回上一步或关闭窗口 |
| ✋ 张开手掌 | 文件页切到任务页；任务页循环切换筛选分类 |
| 🤟 I Love You | 刷新当前列表 |

## 7. Codex 审批

当由 Dock 发起的 Codex 回合请求执行命令或修改文件时，主面板会自动展开并显示审批卡片。

- “仅允许本次”：只批准当前这一项请求。
- “拒绝”：拒绝当前请求。
- 👍 竖起拇指：仅允许本次。
- ✌ 胜利手势：拒绝。

批准前请阅读显示的命令、文件操作和工作目录。系统不会通过手势授予整次会话的持续权限。

Dock 使用独立 App Server 连接，因此不能接管另一个 Codex 客户端已经持有的审批弹窗。Codex Desktop 自己发起的审批仍需在 Codex Desktop 中处理。

## 8. 两层连接状态

主面板的 `CODEX LINK` 区域会显示：

- `Codex Adapter`：App Server 是否连接。它负责任务、文件、回合、事件和审批。
- `Windows Core`：Codex 桌面窗口与应用身份是否验证成功。
- `UIA 只读`：是否完成脱敏的 Windows UI Automation 结构检查。
- `Window Events`：是否正在实时监听已验证 Codex 进程的窗口事件。

`TWO-LAYER ONLINE` 表示 Codex Adapter 已连接；Windows Core、UIA 和 Window Events 各自显示独立状态，便于判断具体问题。

## 9. 暂停 Windows 控制

点击 `CODEX LINK` 区域中的“暂停 Windows 控制”，可以立即阻止所有 Codex 快捷键和 Windows 系统动作。暂停状态会保存，重新启动 Dock 后仍然有效。

暂停后：

- 快速对话、Codex 话筒、代码审查、终端和侧栏等 Windows 动作会被拒绝。
- 显示桌面、任务视图、资源管理器和音量动作也会被拒绝。
- 文件与任务窗口、App Server 任务读取、文件打开和审批功能仍可继续使用。
- 点击“恢复 Windows 控制”后，桌面动作重新启用。

如果怀疑手势误触、窗口焦点异常或 Codex 身份验证异常，请先暂停 Windows 控制。

## 10. 摄像头与隐私

- 摄像头画面、人体关键点和手势识别都在本机处理。
- 默认不录制或上传图像、视频和人体关键点。文档模式只在用户主动拍摄并点击保存后写入一张 PNG；应用不会上传该文件。
- QR 和条码结果只在当前界面内存中显示，除非用户主动复制，否则不会写入剪贴板或本机存储。
- Dock 只在用户明确开启麦克风后读取音频；只计算本机输入电平，不播放、录制、转写或上传。
- `localStorage` 保存按天累计的坐姿统计、已查看文件标记以及所选媒体设备/取景偏好；其中不包含媒体内容。
- Windows 控制审计不记录任务正文、窗口文本、按键内容或摄像头数据。

Windows 控制审计日志位于：

```text
%APPDATA%\codex-gesture-dock\audit\windows-control-YYYY-MM-DD.jsonl
```

日志只记录时间、动作名、目标进程、执行结果、急停状态和身份验证状态。

## 11. 常见问题

### 看不到摄像头画面

1. 打开 Windows“设置 → 隐私和安全性 → 相机”。
2. 允许桌面应用访问摄像头。
3. 关闭占用摄像头的其他程序后重试。
4. 在 Dock 中结束本次监测，再点击“再次开始”。

### 手势没有触发

- 确认“Codex / Windows 手势”开关已打开，并检查下拉框是否选中了需要的模式。
- 让整只手处于画面中，并改善正面光线。
- 手势稳定保持 0.85 秒，不要快速挥动。
- 每次触发后完全松手，再做下一个手势。
- 如果 `Windows Core` 显示已暂停，先点击“恢复 Windows 控制”。

### Codex Adapter 一直显示未连接

- 确认 Codex Desktop 已安装、已登录并正在运行。
- 等待几秒让 Dock 自动发现最新的 Codex Desktop App Server 运行时。
- 退出并重新打开 Codex Gesture Dock。
- 更新到较新的 Codex Desktop 版本。

### Windows Core 显示未就绪

- 打开 Codex Desktop 主窗口。
- 确认使用官方 `OpenAI.Codex` Microsoft Store 包或有效 OpenAI 签名版本。
- 不要使用标题伪装为 Codex 的浏览器或第三方程序。
- 如果刚更新 Codex，完全退出 Codex Desktop 后重新打开。

### UIA 显示待检查，但快捷键可用

UIA 只用于只读结构诊断。当前 Codex WebView 没有暴露稳定的业务控件，桌面动作使用经过身份和前台验证的固定快捷键后端。UIA 暂时不可用不一定影响这些快捷键动作。

### 没有看到刚完成的文件

- 点击“未查看文件”页底部的刷新按钮，或使用 🤟 手势。
- 确认对应 Codex 回合已经完成。
- 已打开过的文件会被记为已查看，不再出现在未查看列表。
- 切换到“Codex 任务”确认任务状态是否为已完成。

### 动作发送到了错误窗口吗

Codex 模式的每个桌面动作执行前都会验证 Codex MSIX/签名身份、目标进程、窗口和最终前台进程；任一检查失败都会取消动作。Windows 模式只发送固定系统组合键，不会把文本发送给前台程序。发现异常时仍应立即使用“暂停 Windows 控制”。

## 12. 键盘、辅助技术与界面恢复

- 使用 `Tab` / `Shift+Tab` 在按钮、开关、筛选和下拉框之间移动，按 `Enter` 或空格激活。
- 在文件与任务窗口中按 `Esc`：确认页返回操作页，操作页返回列表，列表页关闭窗口。
- 当前页签、任务筛选和手势/Windows 控制状态会通过辅助技术可读的状态属性表达，不只依赖颜色。
- Windows 开启“减少动画”后，Dock 会停用非必要动画和过渡。
- 如果 React 界面发生未捕获错误，会显示不含任务正文或本机路径的恢复页；点击“重新加载”恢复。
- Electron renderer 崩溃或持续无响应时会限次自动重载。任务窗口连续失败会单独关闭，不影响主面板；主面板连续失败会明确提示并退出，避免无限重启。

## 13. 退出、自动更新与清理

- 退出：展开主面板并点击右上角 `×`。
- 安装版：启动后约 15 秒自动检查更新，之后每 6 小时检查一次。发现新版本会在后台下载；下载完成后点击 `CODEX LINK` 区域的“重启安装”并再次确认。
- 如果暂不重启，已下载的更新会在之后退出应用时安装。
- 可随时点击 `CODEX LINK` 区域中的“检查更新”。
- portable 版：退出旧版本后，用新版文件替换旧版并重新启动。
- 删除应用：退出后删除便携版程序或解压目录。
- 如需同时清除本机设置、任务绑定和审计日志，可在应用完全退出后删除 `%APPDATA%\codex-gesture-dock`。删除前请确认不再需要其中的审计记录。

## 14. 功能边界

当前 v1 已完成 Codex 两层闭环和 6 项常用 Windows 系统手势，但不会提供以下危险能力：

- 任意 Windows 程序控制
- 任意键盘文字输入
- 任意命令或脚本执行入口
- 任意窗口句柄或 UIA 选择器
- 坐标点击
- 密码框、对话正文或编辑框内容读取

新程序必须增加独立 Adapter、应用身份策略、动作白名单和测试，不能通过现有接口直接获得通用桌面控制权。

自动更新地址固定为本项目 GitHub Releases，界面和手势不能指定其他下载地址。当前未配置 Authenticode 证书，因此自动更新具备版本检查、哈希元数据与用户确认，但 Windows 仍可能显示未知发布者警告；可信静默更新需要后续配置发布证书。

更多技术边界见 [Windows 桌面控制设计](windows-desktop-control.md)。

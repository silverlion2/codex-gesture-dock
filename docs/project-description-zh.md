# Codex Gesture Dock 项目说明

Codex Gesture Dock 是一个隐私优先的 Windows 桌面助手：它用摄像头手势控制
Codex 工作流和一组固定 Windows 动作，并把坐姿辅助、文档扫描、OCR、二维码/
条码和常用图片处理集中到同一个置顶 Electron Dock 中。

## 项目目标

项目面向希望减少鼠标切换、需要本机处理文档与图片、又不愿把摄像头画面、
原始文件或 OCR 内容发送给云端视觉服务的用户。它不是单一扫码器，而是一套
有明确隐私边界、人工复核和导出确认的本机视觉工作台。

## 核心能力

- **Codex 与 Windows 控制：** 6 种稳定保持手势、任务浏览、活跃回合追加、
  审批处理、紧急停止，以及经过应用身份和前台窗口验证的固定 Windows 动作。
- **免手操作：** 可选的空中指针支持本机光标移动、稳定停留后的捏合点击和
  张掌滚动；会话级本机语音控制支持 19 条固定中英文命令。
- **摄像头与坐姿：** 个人坐姿校准、本机姿态评分、提醒、手势指引、人脸隐私、
  表情面具、人物分割和有界物体识别。
- **文档处理：** 摄像头/照片/PDF 导入、透视拉正、旋转增强、页面排序、永久
  遮盖、拍摄质量提示、多语言 OCR、跨页搜索、票据/MRZ 提取和可搜索 PDF。
- **OCR：** 文件与批量 OCR、名片字段和 vCard、逐词置信度复核、人工修正、
  简单表格复核，以及 JSON、CSV、hOCR 1.2、ALTO 4.4 版面导出。
- **二维码与条码：** 摄像头和图片识别、批量结果导出，以及文字、HTTP(S)、
  Wi-Fi 和联系人二维码的本机生成。
- **图片工具：** 图片对比与查重、缩放转换、裁剪旋转、检查、标注、联系表、
  长图拼接/拆分、调整、批处理、水印、截图美化、签名/线稿提取、色彩抠图、
  贴纸描边、人物背景、调色板、对比度检查和色觉模拟。

## 隐私和安全边界

摄像头推理、OCR、扫码、PDF 栅格化、图片处理和固定命令语音识别使用随应用
分发或 Windows 提供的本机运行时与模型。应用不录制视频或语音，不自动上传
原文件或识别结果；只有用户明确点击导出时才写入文件。永久遮盖、背景处理和
OCR 等功能都要求预览或人工复核，检测结果和置信度只作为辅助信息，不作为
准确性、身份、真实性或医学结论。

Codex 控制和 Windows 控制由独立的有界适配层承担。Windows 动作来自固定白
名单，紧急停止状态持久保存在本机，审计日志不记录任务正文、窗口内容、按键、
图片、音频或 OCR 数据。语音控制默认关闭，只在当前会话生效，并且不能批准
Codex 安全确认。

## 技术组成

- React 19、TypeScript、Vite
- Electron Windows 桌面壳
- MediaPipe Tasks 本机姿态、手势、人脸、分割与物体任务
- Windows System.Speech 固定命令本机语音控制
- Tesseract.js 离线英文、简体中文和繁体中文 OCR
- OpenCV.js 与 PDF.js 文档处理
- ZXing 二维码/条码识别与二维码生成
- Vitest、Node test runner、Playwright 与 axe-core 验证

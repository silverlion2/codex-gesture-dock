# Codex Gesture Dock 产品规格

## 产品目标

Codex Gesture Dock 是一个隐私优先的 Windows 桌面辅助应用。它在本机摄像头画面上运行姿态和手势模型，并把明确、经过保持确认的手势映射到两层固定动作：

1. Codex 层：打开任务选择器、控制 Codex 桌面快捷操作、查看任务与最近产出、处理逐次审批。
2. Windows 层：显示桌面、任务视图、资源管理器和系统音量等固定白名单动作。

摄像头帧不离开设备；应用不采集遥测，不保存图像或视频。

## 用户与核心任务

- 长时间使用 Codex 的 Windows 用户：保持摄像头与姿态状态可见，同时用手势完成高频操作。
- 无法持续使用键鼠的用户：通过六种可见手势和明确反馈完成固定动作。
- 对隐私和误触敏感的用户：随时暂停 Windows 控制，并在危险 Codex 请求上逐次确认。

## 发布范围

### 包含

- 始终可见的实时摄像头区域、姿态状态和六种手势说明。
- 同一摄像头工作区内的姿态、QR/条码扫描和文档快照模式；扫码仅保留内存结果，文档仅在用户明确保存后写盘。
- 单独的文件/任务选择窗口，包含最近完成文件、任务筛选、动作选择和确认步骤。
- Codex App Server 本机连接、任务绑定、通知和审批桥接。
- Windows 固定动作白名单、应用身份验证、紧急停止和隐私安全审计日志。
- NSIS 安装版、便携版、GitHub Releases 自动更新、SBOM、校验和与构建来源证明。
- 中文用户手册、Windows 控制手册、隐私政策、安全政策和签名政策。

### 不包含

- 任意文本输入、任意命令执行或通用 Windows UI 自动点击。
- 云端摄像头分析、账户系统、遥测或行为画像。
- macOS/Linux 安装包。
- 在没有有效 Authenticode 签名时宣称消除 SmartScreen 提示。

## 关键用户旅程

1. 首次运行：展开面板 → 用户主动开始监测 → 授予仅视频权限 → 完成四秒校准。
2. 日常使用：在始终置顶的迷你摄像头 Dock 中观察实时画面与状态，按需切换姿态、扫码或文档模式 → 需要设置或完整指标时展开主面板 → 保持手势 0.85 秒 → 看到动作结果 → 手势回到中性后才能再次触发。
3. Codex 操作：张开手掌 → 在独立窗口选择文件或任务 → 选择动作 → 确认执行。
4. 安全恢复：点击紧急停止 → 所有 Codex/Windows 桌面动作立即失败关闭 → 用户主动恢复。
5. 更新：安装版后台检查稳定版本 → 下载完成后提示 → 用户确认重启安装；便携版只提示手动更新。

## 成功标准

| 指标 | 发布标准 | 验证方式 |
|---|---:|---|
| 自动化测试 | 100% 通过 | Vitest、Node test、Playwright |
| 自动无障碍规则 | 0 个 axe violation | Chromium E2E |
| 已知依赖漏洞 | 0 个 high/critical | 官方 npm audit |
| 安装包信任 | 所有可执行文件签名有效且有时间戳 | Authenticode 验证脚本 |
| 更新链路 | 真实 N→N+1 安装、升级、卸载通过 | 隔离 Windows runner |
| 隐私 | 无帧上传、无遥测 | 架构与网络边界审查 |

## 发布决策

- 当前版本必须高于已发布版本，候选提交必须在受保护的 `main` 上通过 CI 与 Security。
- 缺少签名证书、精确签名主体或真实升级证据时，发布流程必须失败关闭。
- 产品代码就绪与公开商业发布是两个独立结论；只有全部发布门禁通过才能标记商业发布完成。

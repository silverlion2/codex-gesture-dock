# Codex Gesture Dock 产品规格

## 产品目标

Codex Gesture Dock 是一个隐私优先的 Windows 桌面辅助应用。它在本机摄像头画面上运行姿态和手势模型，并把明确、经过保持确认的手势映射到两层固定动作：

1. Codex 层：打开任务选择器、控制 Codex 桌面快捷操作、查看任务与最近产出、处理逐次审批。
2. Windows 层：显示桌面、任务视图、资源管理器和系统音量等固定白名单动作。

摄像头帧不离开设备；应用不采集遥测，不保存图像或视频。

## 用户与核心任务

- 长时间使用 Codex 的 Windows 用户：保持摄像头与姿态状态可见，同时用手势完成高频操作。
- 无法持续使用键鼠的用户：通过六种可见手势和明确反馈完成固定动作。
- 对隐私和误触敏感的用户：随时暂停 Windows 控制，并在危险 Codex 请求上逐次确认。

## 发布范围

### 包含

- 扫描文档在全部页面都有有效 OCR 词框后必须提供文档级 JSON/CSV/hOCR/ALTO，严格使用当前页序、每页尺寸和原页文件名。JSON 必须保留 schema 版本、页/词总数与完整页文档；CSV 必须展平页号、源页尺寸/语言及每词坐标、评分和来源，并执行公式中和。hOCR 页写入 0 起算 `ppageno` 和唯一跨页 ID；ALTO 写入多个 Page、1 起算 `PHYSICAL_IMG_NR` 和唯一跨页子节点 ID。任一页缺失时必须禁用按钮，不得默默导出部分文档。
- 扫描页 OCR 必须可选已打包的简中 + English、繁中 + English 或 English；单页与“未识别页”批次在开始时捕获选择，每页结果保留实际语言。切换选项不得改写已完成页的版面语言。
- 完成任一扫描页 OCR 后必须可用最多 200 字符在当前人工修正文本中不区分大小写搜索。结果按当前页序返回页内次数和有界摘要，“下一匹配页”从当前位置循环；无结果时禁用，查询不得持久化或改动 OCR/像素。
- 多页质量与隐私复核必须有文档级导航：“下一质量问题页”在非 good 页中按页序循环，只显示建议，不禁用 OCR/导出；“下一敏感页”显示疑似总数/页数，在含 PII 建议页中循环并载入手动遮盖编辑器，不得自动应用遮盖。

- 始终可见的实时摄像头区域、姿态状态和六种手势说明。
- 迷你 Dock 中的摄像头/麦克风设备选择、填满/完整取景、镜像和明确的麦克风开关；音频仅用于本机输入电平，不播放、不录制。
- 同一视觉工作区内的姿态、QR/条码、智能文档扫描、文件 OCR、名片 OCR、人脸隐私、人物背景、物体识别、图片对比/查重/优化/裁剪/检查/标注/联系表/长图/调整/水印/线稿抠图/色彩抠图/贴纸描边和颜色实验室；扫码、扫描页、OCR、模型、图片分析与颜色结果仅保留内存，PNG/JPEG/WebP/PDF/TXT/VCF/JSON/CSV/CSS 仅在用户明确保存、复制或导出后离开当前工具状态。
- QR/条码模式在实时摄像头外还支持不申请摄像头权限的本机图片导入；单个 PNG/JPEG/WebP/BMP 最大 35 MB，也可批量选择 2–20 张且合计不超过 200 MB。批量必须按可见文件顺序串行解码、显示进度并可取消；单张未找到或失败不得中止后续文件。结果必须区分成功、未找到和错误，可导出含文件名、状态、格式、内容与错误的 UTF-8 CSV，并防止 `=`、`+`、`-`、`@` 开头单元格触发表格公式。每次解码后必须撤销对象 URL，错误不得阻止用户换图或继续启动实时扫描；任何路径都不得自动打开识别到的网址。
- QR 生成与识别共用一个二级工作区，可离线生成文字、HTTP(S) 网址、Wi-Fi 和 vCard 联系人二维码。内容必须非空且不超过 2500 UTF-8 字节；网址只接受完整 `http://` 或 `https://`，Wi-Fi/vCard 字段必须转义协议分隔符并移除换行，防止插入额外记录。支持 256、512、1024px 预览及明确导出 SVG/PNG、复制原始内容；修改类型、字段或尺寸后旧预览必须失效。应用不得自动导航、联网或写入系统网络/联系人，所有输出只由用户主动复制或下载，并持续提示跨设备试扫复核。
- 智能文档扫描支持摄像头、照片或最多 20 页/35 MB 的 PDF 输入、自动纸张边缘检测、可拖动且支持键盘微调的手动四角矫正、透视矫正、左右 90° 页面旋转、彩色/灰度/黑白增强、多页添加/删除/前后排序、单页 PNG、多页 PDF，以及把矫正页交给本地 OCR。排序必须移动完整页面及其遮盖、旋转、质量与 OCR 复核状态，并直接决定缩略图编号和 PDF 导出顺序；首尾移动按钮必须禁用。旋转必须同步转换已有遮盖框、清除旧 OCR/PII/票据/MRZ 结果，并在滤镜或角点重处理后恢复方向再应用遮盖。每页必须对原图做有界的本机质量分析，显示分辨率、亮度、对比度、清晰度与疑似局部反光问题；这些启发式建议不得自动拒绝 OCR 或导出。导入 PDF 必须在本机逐页栅格化并明确告知原文本层、表单、链接和批注不会保留，不得把它描述为原生 PDF 编辑。
- 扫描页支持人工绘制、键盘微调、撤销与复核隐私遮盖；用户确认后必须把遮盖永久烧录进当前栅格，PNG、PDF 与 OCR 不得继续读取未遮盖页，滤镜重处理不得静默丢失已有遮盖。
- 扫描页 OCR 可按文字坐标保守提示疑似邮箱、电话、中国大陆身份证号和通过 Luhn 校验的金融卡号；建议必须进入同一人工遮盖编辑器，禁止自动应用，且界面必须要求用户检查误检与漏检。
- 扫描页 OCR 文本和坐标建议必须按页面标识保留；文字可人工编辑并一键恢复识别原文，复制、结构化提取和 TXT 使用当前复核文本。逐词复核必须保留坐标、引擎置信度和首次识别来源，在用户明确应用后同步重算 PII 建议；恢复必须同时还原原文、原词框与建议。整段自由编辑不得伪称更新坐标建议。切换、排序不得丢失，任何改变该页像素或坐标的旋转、拉正、滤镜、永久遮盖和删除操作必须只使对应页结果失效。提供严格串行的“OCR 未识别页”，取消或单页失败保留已完成结果；合并 TXT 按当前页序输出并区分尚未 OCR 与人工复核后为空的页面。
- 可搜索扫描 PDF 必须失败关闭：只有当前顺序中的每一页都有至少一个有效、非空、有限且限制到页面内的 OCR 词框时才可导出。输出必须保留当前已处理栅格为可见页，并以不可见 Unicode 层写入当前逐词复核文字；混合 CJK/非 CJK run 必须保持可提取，离线 OFL 中文字体只在明确导出时加载且只嵌入使用字形。逐词修正不得移动词框或篡改引擎置信度；人工编辑整段 OCR 文本不得伪称重排文字层。旋转、重处理或永久遮盖必须先使对应页 OCR 失效。自动测试必须用独立 PDF.js 读回中文、英文、数字与页序，不能只 mock PDF 写入调用。
- 矫正页 OCR 可选地预填票据/发票的商户、日期、单据号、小计、税额、总额和币种；结构化结果可编辑，只有用户确认后才能复制 JSON 或导出 CSV。
- 文件 OCR 与矫正页 OCR 可选地提取 ICAO TD1/TD2/TD3 机器可读区；必须显示格式、校验位结果、字段错误和字段类型约束下的 OCR 易混字符修正数，允许编辑字段，并在用户明确确认对照原证件前禁止复制/导出 JSON。产品不得把 MRZ 校验位描述为证件真实性、身份真实性或有效性验证。
- 最多一次选择 20 个 PNG、JPEG、WebP 或 PDF 的离线中英文批量 OCR；逐文件显示进度、结果和错误，支持取消、单独 TXT 与按原顺序合并 TXT。名片 OCR 必须提供单张/批量切换；批量一次最多 20 张图像，逐张保存独立 OCR、词框和可编辑姓名/公司/职位/电话/邮箱/网站/地址/备注，支持所选 VCF 与按当前成功项顺序拼接的合并 VCF。两个导出都必须写明“确认”，不得调用系统联系人。固定语言文件/名片批次和“未识别扫描页”必须严格串行复用一个短生命周期 OCR worker，禁止并发识别或逐项重复加载同一模型；取消、运行时失败和批次结束必须确定性释放或丢弃 worker。每个 PDF 最多 20 页。
- 图像文件、名片和扫描页 OCR 必须允许按 Tesseract 词级置信度复核原图：默认阈值 80，可在 50–95 间调整，按最低分优先提示，并给出平均值、最低值、待复核和已复核数量。必须可切换到包括高分词的全部有效框，按原词索引阅读顺序每组最多 100 个稳定分页，跨组记录不丢失。每词修正最多 200 字符，须先记录再明确应用，空值删除误检；按同文词出现顺序精确匹配，重复索引、无效索引、超限、重复数量不一致或无法定位必须失败关闭。修正同步到当前 TXT/名片解析/版面导出及扫描页可搜索 PDF，保留首次识别文字、原坐标和引擎置信度。该值必须描述为启发式评分而非正确概率；PDF 内嵌文本层没有 Tesseract 词框时不显示复核入口。
- 图像文件、名片和扫描页 OCR 在存在有效词框时必须提供明确的版面 JSON/CSV/hOCR/ALTO 导出。schema v1 JSON/CSV 固定使用左上角像素坐标，并同时输出 0–1 归一化坐标、原图文件名/尺寸、语言、行分组、词序、文本与引擎置信度；hOCR 必须声明页面/行/词能力，输出页面、行、词 `bbox`、整数 `x_wconf` 与已知语言映射。ALTO 必须使用官方 4.4 schema、v4 命名空间和 pixel 量纲，输出 Page / PrintSpace / TextBlock / TextLine / String 层级，把置信度转换到 0–1 `WC`，逐词人工复核写入 `CS` 和原识别 `ALTERNATIVE`。HTML/XML 必须转义源文件名和识别文本。无效框过滤、越界框限制、文件名净化和 CSV 公式注入防护必须确定性执行。整段人工修改 OCR 文本或名片字段不得伪称更新词框；PDF 内嵌文本层没有 Tesseract 坐标时不得显示入口。
- OCR 表格辅助只能复用图像、名片和扫描页的原始 Tesseract 词框，不得额外上传或调用文档模型。它必须过滤无效框并限制到最多 5000 个词，按 `lineId` 排行、以页面宽度和中位字符宽度确定大间隔，再在垂直连续区域中寻找至少 3 行、最多 200 行、支持率至少一半、2–8 列的重复对齐分隔；多个候选只显示行数优先的最大一块。找不到候选时必须失败关闭并引导使用版面 JSON/CSV，超过 200 行须要求拆图。候选必须在带行列标签的模态表格中逐格可编辑，显示使用/忽略词数和对齐复核等级，Escape/关闭后恢复触发按钮焦点。只有明确确认才导出安全文件名、UTF-8 BOM、CRLF、全字段引号且中和 `= + - @` 公式前缀的 CSV。必须持续说明它不识别合并单元格、跨页表头、嵌套表格或字段语义，结果须对照原图人工复核。
- 人脸与照片隐私：本机自动检测多张人脸，逐张人工启用/跳过；必须允许添加手动隐私区，并通过拖动、方向键/Shift、Alt + 方向键和 Delete 完成有界的位置、大小与删除复核。提供模糊、像素化、黑色遮盖和保护范围选择；JPEG/PNG 同时检查常见 EXIF/GPS 位置、设备、序列号、时间和作者字段，WebP/BMP 必须明示检查范围受限。无论是否检测到人脸，都必须通过 canvas 重新编码 PNG，且不得复制原文件的 EXIF、GPS、XMP、IPTC 或 ICC 数据；只有用户明确导出才写盘，并持续提示自动检测可能漏检、元数据检查不等同于画面内容取证。
- 人物照片背景：本机生成前景置信度蒙版，提供透明移除、背景模糊、纯色替换和用户明确选择的另一张本机图片背景，人物阈值、边缘柔化与原图对照可调整。人物图与自定义背景只接受单张最大 35 MB 的 PNG/JPEG/WebP/BMP，解码后超过 8000 万像素必须拒绝；背景图只留当前 renderer 内存，可用确定性的铺满裁切或完整显示布局，并提供 0%–100% 水平/垂直位置和完整显示时的留边颜色。移除或重置必须释放组件引用，任何图片都不得上传或持久化；导出前持续提示背景裁切、留边、人物边缘和内容授权复核。必须允许用有界的“保留人物/移除背景”软边画笔修正漏选与误选，提供画笔大小、撤销、清空、取消回滚和明确应用，且不得涂改原始照片。纯色模式可选保留原比例、一寸 295 × 413、二寸 413 × 579、35 × 45 mm 的 413 × 531 或 2 × 2 inch 的 600 × 600 像素画布，并通过 0%–100% 垂直构图控制有界裁切；可进一步把最大整数份照片居中排列到 1800 × 1200 像素、4 × 6 inch/300 DPI 白底画布并绘制浅色切边框。界面必须提示按 100%/实际尺寸打印并关闭“适应页面”。同时复用本机人脸检测提示零张、多张或单张人脸；单人时报告裁切后脸框高度占画布比例与水平偏移，并仅以公开固定阈值提示明显偏小、偏大、偏心或触边。这些尺寸和构图信号仅提供排版辅助，不得声称自动满足任何证件、护照或机构规范。只有找到有效人物并由用户“确认并导出”才写出 PNG，持续提示自动分割、手动边缘和机构受理的复核限制。
- 单帧/照片物体识别：用户明确捕获当前摄像头一帧或选择照片后，可用内置模型定位 80 类常见 COCO 物体，也可临时导入最大 100 MB、带 MediaPipe 检测元数据的可信 `.tflite` 模型与可选标签 TXT。导入模型必须先完成本机格式和运行时兼容性验证，失败时保留当前模型；不上传、不持久化，且可一键恢复内置模型。两条路径都提供置信度筛选、逐框启用/跳过、结构化 JSON 与标注 PNG。不得持续分析视频；复制和导出只包含当前人工复核选择，持续提示标签覆盖、误检与漏检限制，禁止直接触发自动化动作。
- 图片对比：用户明确选择两张最大 35 MB 的 PNG/JPEG/WebP/BMP 后，在本机生成统一有界画布、滑动对照和 Pixelmatch 感知差异热图。必须提供键盘可访问的分界控制、严格/推荐/宽松容差、差异像素/占比/包围框、原始与对比尺寸，并在尺寸不同、缩放发生或无差异时保持语义准确。尺寸不同按左上角对齐并补白，不得静默拉伸；只有明确操作才导出重新编码的差异 PNG。像素相似度不得宣称证明功能正确、语义等价、视觉质量或无障碍合规。
- 批量重复图片查找：用户可明确选择 2–20 张 PNG/JPEG/WebP/BMP，单张最大 35 MB、合计最大 200 MB；系统必须串行生成白底 9×9 亮度采样的 128 位双方向 dHash、有界 JPEG 缩略图和可用时的 SHA-256。候选按精确重复优先、Hamming 距离升序显示，提供 2/8/16 三档最大距离、部分失败与取消状态；字节摘要一致可标为完全相同，其他结果只能描述为近重复候选。不得自动删除、移动、重命名或修改源文件，也不得把 dHash 当作语义相似、身份或内容安全判断。
- 单图优化：用户明确选择一张最大 35 MB 的 PNG/JPEG/WebP/BMP 后，可保持宽高比并禁止放大地输出 PNG、JPEG 或 WebP，最长边提供原尺寸受限、2048、1600、1200、800 像素预设；输出硬限制为最长边 8192 像素、总计 2400 万像素。JPEG/WebP 品质必须在 40%–100%，PNG 明确禁用品质控件；JPEG 必须以白色合成透明像素。编码器返回 MIME 与请求格式不一致时必须失败关闭，不得静默用错误扩展名。结果显示输入/输出体积、尺寸、格式和体积增减，明确提示浏览器原生编码不等同于专业无损压缩；重新编码不复制源元数据，只有“确认并导出”才写盘且不得修改源文件。
- 单图裁剪与旋转：同一图片分析入口必须支持一张最大 35 MB 的 PNG/JPEG/WebP/BMP，提供自由、1:1、4:3、3:4、16:9 裁剪、三分法网格、指针/触控拖动和键盘微调，以及左右 90° 旋转、水平翻转和垂直翻转。旋转与翻转可组合，必须每次从原文件生成，不对上次预览累计重编码；工作栅格复用最长边 8192 像素/2400 万像素上限并明确显示安全缩放。响应式百分比裁剪坐标必须直接映射回工作栅格，使面板缩放不改变导出区域，并限制越界、拒绝宽或高小于 8 像素的区域。PNG/JPEG/WebP 输出、40%–100% 品质、PNG 禁用品质、JPEG 白底、MIME 回退验证、安全文件名、对象 URL 释放和源文件不覆盖规则与优化工作区一致。只有生成预览并目视复核后，“确认并导出”才能写盘。

## 发布决策

### 批量图片转换验收

- 同一图片分析入口接收 1–20 张 PNG/JPEG/WebP/BMP，单张最大 35 MB、合计最大 200 MB；用户可调整顺序和移除项目。
- 支持保留原尺寸或最长边 3200/2048/1600/1080/640 像素，不得放大小图；每个输出最长边不超过 8192 像素且不超过 2400 万像素。
- 支持 PNG/JPEG/WebP、40%–100% JPEG/WebP 品质、原名加编号或纯编号、安全前后缀与 0–999999 起始编号；Windows 保留名和非法字符必须安全化，三位顺序号避免同名覆盖。
- 任何设置或顺序变化都使首图预览失效；只有重新生成并滑动复核首图后才能逐张导出。每张处理完成后立即请求下载和释放临时 URL，不同时保留整批结果 Blob。
- 重新编码不得复制 EXIF/GPS 或覆盖源文件；JPEG 透明区域转白，格式编码不受支持时明确失败，并报告失败前已请求下载的数量。

### 截图美化验收

- 接收一张最大 35 MB、解码后最大 8000 万像素的 PNG/JPEG/WebP/BMP，仅在本机内存处理。
- 提供六种内置背景、自动/1:1/4:3/16:9 画布、4%–24% 留白、0%–8% 圆角、0%–100% 阴影及无边框/窗口栏；窗口标题最大 50 字符。
- 固定比例只能扩展背景，不裁切或拉伸源截图；窗口栏必须被描述为装饰，不得声称证明原始应用或内容来源。
- 预览限制到最长边 1600/240 万像素，最终输出限制到 8192/2400 万像素。任何样式变化都清除旧预览；只有重新预览后才能明确导出 PNG/JPEG/WebP。
- JPEG 透明区域转为当前背景结果；所有格式均重新编码且不复制 EXIF/GPS，不覆盖源截图或保存可编辑工程。

### 线稿抠图验收

- 接收一张最大 35 MB、解码后最大 8000 万像素的 PNG/JPEG/WebP/BMP；源文件、工作像素与结果只留 renderer 内存。
- 支持浅色/深色背景、0–255 阈值、0–64 柔化、原色/六位 HEX 纯色、自动裁边与 0–128 像素留白；源 alpha 参与结果，完全透明像素必须清除隐藏 RGB，空掩版必须拒绝。
- 预览限制到最长边 1600/240 万像素，最终结果从源文件重新处理并限制到 8192/2400 万像素；修改任一设置后旧预览失效。
- 只有复核后才可明确导出透明 PNG；不复制 EXIF/GPS、不覆盖源文件。界面持续说明纸纹、阴影、正文和表格线也可能被保留，且该亮度工具不识别签名身份、不验证真实性/授权/法律效力，也不能作为隐私删除手段。

### 色彩抠图验收

- 接收一张最大 35 MB、解码后最大 8000 万像素的 PNG/JPEG/WebP/BMP；源文件、取样色、工作像素与结果只留 renderer 内存。
- 点击原图须使用有界 alpha 加权邻域取样，同时支持颜色选择器；sRGB→OKLab 色距、0–100 容差/柔化/溢色中和、源 alpha、只中和中间-alpha 边缘、保持不受影响主体、完全透明 RGB 清零及无可见/全部移除失败关闭须有确定测试。
- 预览限制到最长边 1600/240 万像素，最终结果从源文件重新处理并限制到 8192/2400 万像素；修改目标色、容差或柔化后旧预览失效。
- 只有复核同色主体、反光、阴影、压缩噪点及边缘后才可明确导出透明 PNG；不复制 EXIF/GPS、不覆盖源文件。界面持续说明算法全局移除相近颜色，不理解前景/背景；溢色中和可能让真实彩色细边变灰，不是物理重建或专业去溢色，也不能用于隐私删除。

### 贴纸描边验收

- 只接受一张最大 35 MB、解码后最大 8000 万像素且有真实透明边界的 PNG/WebP；不透明 JPEG/BMP、全透明和全不透明输入须给出可恢复错误。
- `alpha > 4` 主体裁边、短边 1%–8% 描边、0%–8% 留白、六位 HEX、两遍 3-4 chamfer 距离及源 RGB/alpha 原样覆盖必须有确定测试；窄孔和相邻部件的连接风险持续可见。
- 预览源限制到 1200 边/150 万像素，最终工作源限制到 3000 边/800 万像素，结果限制到 4096 边/1400 万像素；分行处理可取消，设置变化使旧结果失效。
- 结果须能在棋盘格、白底和黑底切换复核而不重新处理；只有明确确认才导出不复制元数据、不覆盖源文件的透明 PNG。界面不得把栅格轮廓描述为主体识别、矢量刀模、出血线或印刷尺寸。

### 表情动态面具验收

- 用户可从摄像头模式切换到“面具”，选择霓虹狐、机甲面罩或庆典假面；摄像头未启动时有明确启动入口。
- 面具必须随脸部位置、尺度和转动对齐，并对眨眼、抬眉、微笑与张嘴做可见响应；失去人脸、模型加载和模型错误都有文字状态。
- Face Landmarker 模型随包分发，只在本机按需加载；视频帧、关键点和 blendshape 不上传、不持久化，也不得宣称识别身份或真实情绪。

- 当前版本必须高于已发布版本，候选提交必须在受保护的 `main` 上通过 CI 与 Security。
- 缺少签名证书、精确签名主体或真实升级证据时，发布流程必须失败关闭。
- 产品代码就绪与公开商业发布是两个独立结论；只有全部发布门禁通过才能标记商业发布完成。

# Codex Gesture Dock 产品规格

## 产品目标

Codex Gesture Dock 是一个隐私优先的 Windows 桌面辅助应用。它在本机摄像头画面上运行姿态和手势模型，并把明确、经过保持确认的手势映射到两层固定动作：

1. Codex 层：打开任务选择器、控制 Codex 桌面快捷操作、查看任务与最近产出、处理逐次审批。
2. Windows 层：显示桌面、任务视图、资源管理器和系统音量等固定白名单动作。

摄像头帧不离开设备；应用不采集遥测，不保存图像或视频。

## 用户与核心任务

- 长时间使用 Codex 的 Windows 用户：保持摄像头与姿态状态可见，同时用手势完成高频操作。
- 无法持续使用键鼠的用户：通过六种可见手势和明确反馈完成固定动作。
- 对隐私和误触敏感的用户：随时暂停 Windows 控制，并在危险 Codex 请求上逐次确认。

## 发布范围

### 包含

- 始终可见的实时摄像头区域、姿态状态和六种手势说明。
- 迷你 Dock 中的摄像头/麦克风设备选择、填满/完整取景、镜像和明确的麦克风开关；音频仅用于本机输入电平，不播放、不录制。
- 同一视觉工作区内的姿态、QR/条码、智能文档扫描、文件 OCR、名片 OCR、人脸隐私、人物背景、物体识别、图片对比/查重/优化/裁剪/检查/标注/联系表/长图/调整/水印和颜色实验室；扫码、扫描页、OCR、模型、图片分析与颜色结果仅保留内存，PNG/JPEG/WebP/PDF/TXT/VCF/JSON/CSV/CSS 仅在用户明确保存、复制或导出后离开当前工具状态。
- QR/条码模式在实时摄像头外还支持不申请摄像头权限的本机图片导入；单个 PNG/JPEG/WebP/BMP 最大 35 MB，一次性解码后必须撤销对象 URL，错误不得阻止用户换图或继续启动实时扫描。
- 智能文档扫描支持摄像头、照片或最多 20 页/35 MB 的 PDF 输入、自动纸张边缘检测、可拖动且支持键盘微调的手动四角矫正、透视矫正、左右 90° 页面旋转、彩色/灰度/黑白增强、多页添加/删除/前后排序、单页 PNG、多页 PDF，以及把矫正页交给本地 OCR。排序必须移动完整页面及其遮盖、旋转、质量与 OCR 复核状态，并直接决定缩略图编号和 PDF 导出顺序；首尾移动按钮必须禁用。旋转必须同步转换已有遮盖框、清除旧 OCR/PII/票据/MRZ 结果，并在滤镜或角点重处理后恢复方向再应用遮盖。每页必须对原图做有界的本机质量分析，显示分辨率、亮度、对比度、清晰度与疑似局部反光问题；这些启发式建议不得自动拒绝 OCR 或导出。导入 PDF 必须在本机逐页栅格化并明确告知原文本层、表单、链接和批注不会保留，不得把它描述为原生 PDF 编辑。
- 扫描页支持人工绘制、键盘微调、撤销与复核隐私遮盖；用户确认后必须把遮盖永久烧录进当前栅格，PNG、PDF 与 OCR 不得继续读取未遮盖页，滤镜重处理不得静默丢失已有遮盖。
- 扫描页 OCR 可按文字坐标保守提示疑似邮箱、电话、中国大陆身份证号和通过 Luhn 校验的金融卡号；建议必须进入同一人工遮盖编辑器，禁止自动应用，且界面必须要求用户检查误检与漏检。
- 扫描页 OCR 文本和坐标建议必须按页面标识保留；文字可人工编辑并一键恢复识别原文，复制、结构化提取和 TXT 使用当前复核文本，但编辑文字不得伪称更新坐标建议。切换、排序不得丢失，任何改变该页像素或坐标的旋转、拉正、滤镜、永久遮盖和删除操作必须只使对应页结果失效。提供严格串行的“OCR 未识别页”，取消或单页失败保留已完成结果；合并 TXT 按当前页序输出并区分尚未 OCR 与人工复核后为空的页面。
- 矫正页 OCR 可选地预填票据/发票的商户、日期、单据号、小计、税额、总额和币种；结构化结果可编辑，只有用户确认后才能复制 JSON 或导出 CSV。
- 文件 OCR 与矫正页 OCR 可选地提取 ICAO TD1/TD2/TD3 机器可读区；必须显示格式、校验位结果、字段错误和字段类型约束下的 OCR 易混字符修正数，允许编辑字段，并在用户明确确认对照原证件前禁止复制/导出 JSON。产品不得把 MRZ 校验位描述为证件真实性、身份真实性或有效性验证。
- 最多一次选择 20 个 PNG、JPEG、WebP 或 PDF 的离线中英文批量 OCR；逐文件显示进度、结果和错误，支持取消、单独 TXT 与按原顺序合并 TXT。固定语言批次和“未识别扫描页”必须严格串行复用一个短生命周期 OCR worker，禁止并发识别或逐项重复加载同一模型；取消、运行时失败和批次结束必须确定性释放或丢弃 worker。每个 PDF 最多 20 页；名片字段必须可编辑并由用户确认后导出 VCF。
- 图像文件、名片和扫描页 OCR 必须允许按 Tesseract 词级置信度复核原图：默认阈值 80，可在 50–95 间调整，按最低分优先显示最多 100 个有效词框，并给出平均值、最低值和阈值下数量。该值必须描述为启发式评分而非正确概率；复核选择不得自动修改 OCR 文本、名片字段或导出内容。PDF 内嵌文本层没有 Tesseract 词框时不显示复核入口。
- 图像文件、名片和扫描页 OCR 在存在有效词框时必须提供明确的版面 JSON/CSV 导出。schema v1 固定使用左上角像素坐标，并同时输出 0–1 归一化坐标、原图文件名/尺寸、语言、行分组、词序、文本与原始置信度；无效框过滤、越界框限制、文件名净化和 CSV 公式注入防护必须确定性执行。人工修改 OCR 文本或名片字段不得伪称更新识别时的词框；PDF 内嵌文本层没有 Tesseract 坐标时不得显示入口。
- 人脸与照片隐私：本机自动检测多张人脸，逐张人工启用/跳过；必须允许添加手动隐私区，并通过拖动、方向键/Shift、Alt + 方向键和 Delete 完成有界的位置、大小与删除复核。提供模糊、像素化、黑色遮盖和保护范围选择；JPEG/PNG 同时检查常见 EXIF/GPS 位置、设备、序列号、时间和作者字段，WebP/BMP 必须明示检查范围受限。无论是否检测到人脸，都必须通过 canvas 重新编码 PNG，且不得复制原文件的 EXIF、GPS、XMP、IPTC 或 ICC 数据；只有用户明确导出才写盘，并持续提示自动检测可能漏检、元数据检查不等同于画面内容取证。
- 人物照片背景：本机生成前景置信度蒙版，提供透明移除、背景模糊和纯色替换，人物阈值、边缘柔化与原图对照可调整；必须允许用有界的“保留人物/移除背景”软边画笔修正漏选与误选，提供画笔大小、撤销、清空、取消回滚和明确应用，且不得涂改原始照片；只有找到有效人物并由用户“确认并导出”才写出 PNG，持续提示自动分割和手动边缘的复核限制。
- 单帧/照片物体识别：用户明确捕获当前摄像头一帧或选择照片后，可用内置模型定位 80 类常见 COCO 物体，也可临时导入最大 100 MB、带 MediaPipe 检测元数据的可信 `.tflite` 模型与可选标签 TXT。导入模型必须先完成本机格式和运行时兼容性验证，失败时保留当前模型；不上传、不持久化，且可一键恢复内置模型。两条路径都提供置信度筛选、逐框启用/跳过、结构化 JSON 与标注 PNG。不得持续分析视频；复制和导出只包含当前人工复核选择，持续提示标签覆盖、误检与漏检限制，禁止直接触发自动化动作。
- 图片对比：用户明确选择两张最大 35 MB 的 PNG/JPEG/WebP/BMP 后，在本机生成统一有界画布、滑动对照和 Pixelmatch 感知差异热图。必须提供键盘可访问的分界控制、严格/推荐/宽松容差、差异像素/占比/包围框、原始与对比尺寸，并在尺寸不同、缩放发生或无差异时保持语义准确。尺寸不同按左上角对齐并补白，不得静默拉伸；只有明确操作才导出重新编码的差异 PNG。像素相似度不得宣称证明功能正确、语义等价、视觉质量或无障碍合规。
- 批量重复图片查找：用户可明确选择 2–20 张 PNG/JPEG/WebP/BMP，单张最大 35 MB、合计最大 200 MB；系统必须串行生成白底 9×9 亮度采样的 128 位双方向 dHash、有界 JPEG 缩略图和可用时的 SHA-256。候选按精确重复优先、Hamming 距离升序显示，提供 2/8/16 三档最大距离、部分失败与取消状态；字节摘要一致可标为完全相同，其他结果只能描述为近重复候选。不得自动删除、移动、重命名或修改源文件，也不得把 dHash 当作语义相似、身份或内容安全判断。
- 单图优化：用户明确选择一张最大 35 MB 的 PNG/JPEG/WebP/BMP 后，可保持宽高比并禁止放大地输出 PNG、JPEG 或 WebP，最长边提供原尺寸受限、2048、1600、1200、800 像素预设；输出硬限制为最长边 8192 像素、总计 2400 万像素。JPEG/WebP 品质必须在 40%–100%，PNG 明确禁用品质控件；JPEG 必须以白色合成透明像素。编码器返回 MIME 与请求格式不一致时必须失败关闭，不得静默用错误扩展名。结果显示输入/输出体积、尺寸、格式和体积增减，明确提示浏览器原生编码不等同于专业无损压缩；重新编码不复制源元数据，只有“确认并导出”才写盘且不得修改源文件。
- 单图裁剪与旋转：同一图片分析入口必须支持一张最大 35 MB 的 PNG/JPEG/WebP/BMP，提供自由、1:1、4:3、3:4、16:9 裁剪、三分法网格、指针/触控拖动和键盘微调，以及左右 90° 旋转。旋转必须每次从原文件生成，不对上次预览累计重编码；工作栅格复用最长边 8192 像素/2400 万像素上限并明确显示安全缩放。响应式百分比裁剪坐标必须直接映射回工作栅格，使面板缩放不改变导出区域，并限制越界、拒绝宽或高小于 8 像素的区域。PNG/JPEG/WebP 输出、40%–100% 品质、PNG 禁用品质、JPEG 白底、MIME 回退验证、安全文件名、对象 URL 释放和源文件不覆盖规则与优化工作区一致。只有生成预览并目视复核后，“确认并导出”才能写盘。
- 单图图片检查：同一图片分析入口必须支持一张最大 35 MB 的 PNG/JPEG/WebP/BMP，在最长边 2400 像素、总计 400 万像素的透明本机画布上生成 64 档亮度/R/G/B 直方图。必须显示原图尺寸、方向、约分宽高比、文件大小、分析缩放、平均亮度、亮度标准差、拉普拉斯边缘响应、近黑/近白截断比例以及全透明/半透明比例；完全透明像素必须从曝光与直方图计算中排除。复核信号必须使用确定性阈值并说明插画、文字、纹理、柔焦和缩放可能影响结果，不得输出主观质量、对焦、真实性或无障碍结论。只有明确点击才导出安全文件名的 schema v1 JSON。
- 单图图片标注：同一图片分析入口必须支持一张最大 35 MB 的 PNG/JPEG/WebP/BMP，在最长边 8192 像素、总计 2400 万像素的本机工作栅格上添加矩形、箭头、编号、文字和局部模糊。标注使用有界归一化坐标，最多 100 项，框和箭头不得小于 8 像素；指针流程必须有“在中心添加”键盘替代，列表项支持方向键/Shift 微调和 Delete。撤销/重做只保留内存历史；扁平渲染必须先写入模糊，再覆盖可见标注。只有生成预览并目视复核后才可导出安全文件名、无源元数据的新 PNG，不得覆盖源文件或持久化可编辑工程。
- 批量图片联系表：同一图片分析入口必须支持用户明确选择 2–20 张 PNG/JPEG/WebP/BMP，单张最大 35 MB、合计最大 200 MB。必须按用户可见顺序提供逐项上移、下移和移除，并支持 2–5 列、1200/1600/2048/3200 请求宽度、1:1/4:3/3:4 单格、完整显示/居中填满、浅色/深色背景、三档间距及可选序号/文件名。输出布局必须确定性限制到最长边 8192 像素和 2400 万像素并显示实际尺寸/安全缩放；图片必须按顺序逐张解码绘制，避免同时保留所有解码位图。居中填满必须明示可能裁边；只有生成预览并目视复核后才可导出安全文件名、不复制源元数据的扁平 PNG，不得改写源图片或持久化布局工程。
- 长图拼接与拆分：同一图片分析入口必须把两种模式明确分开。拼接接收 2–12 张 PNG/JPEG/WebP/BMP，单张最大 35 MB、合计最大 160 MB，提供可见顺序上移/下移/移除、纵向/横向、0/8/24 px 间距、白色/深色/透明背景，以及后续每张 0%–50% 顶部或左侧手动裁去；第一张不得裁去。拼接必须以最小交叉轴尺寸统一图片而不放大小图，并明确手动裁去不等于自动重叠识别。拆分接收一张最大 35 MB 图片，按纵向或横向把全部源像素连续、无重复地等分为 2–12 份，提供逐份与批量明确导出。解码后超过 8000 万像素的源图必须拒绝；拼接整体和每个拆分 PNG 必须分别满足最长边 8192 像素及 2400 万像素预算。所有结果都须先生成预览、显示尺寸/安全缩放并人工复核；重新编码 PNG 不复制源元数据、不改写源图片、不持久化工程。
- 图片调整：同一图片分析入口接收一张最大 35 MB 的 PNG/JPEG/WebP/BMP，提供曝光 -2 至 +2 EV、对比度/饱和度/色温 -100 至 +100、灰度 0%–100%，以及中性、鲜明、暖调、冷调、黑白和褪色预设。像素处理必须固定为曝光→对比度→色温→饱和度→灰度，保留 alpha，并在 UI 说明这不是 RAW、色彩管理或专业校色。预览必须限制到最长边 1600 像素和 240 万像素，最终输出限制到最长边 8192 像素和 2400 万像素；解码后超过 8000 万像素的源图必须拒绝。前后滑动对照、设置摘要、PNG/JPEG/WebP 与 JPEG 白底语义必须可见；设置变化后旧预览失效，只有重新生成预览并明确确认才可导出。处理须可取消、不得覆盖源文件或复制源元数据。
- 批量可见水印：同一图片分析入口接收 1–12 张 PNG/JPEG/WebP/BMP，单张最大 35 MB、合计最大 160 MB；用户必须能调整可见顺序并移除项目。水印支持 1–80 字符文字或最大 10 MB 的 PNG/JPEG/WebP Logo、九个锚点或全图平铺、10%–100% 不透明度、4%–40% 尺寸、0%–15% 边距及 -45°–45° 旋转；文字必须提供黑/白及反色描边以保持可见。首图预览限制到最长边 1600 像素和 240 万像素，最终每张限制到最长边 8192 像素和 2400 万像素，解码超过 8000 万像素须拒绝。设置变化使旧预览失效；只有滑动复核首图后才能逐张生成 PNG/JPEG/WebP，并报告部分失败前已请求下载的数量。Logo、结果及对象 URL 只留内存，不覆盖源文件或复制元数据；必须持续说明可见水印不等于不可移除的版权证明、隐形水印或内容来源认证。
- 颜色实验室：用户明确选择一张最大 35 MB 的 PNG/JPEG/WebP/BMP 后，在最长边 2400 像素、总计 400 万像素的本机白底画布中提取最多 6 个去重后的 OKLCH 代表色。必须允许从图片和调色板分别选取或手工输入文字色/背景色，显示 WCAG 2 AA/AAA 正文与大字阈值，支持交换颜色，并只在明确操作后复制 CSS 变量或 JSON。透明像素按白色合成、缩放必须可见；纯色比率不得宣称已判断图片中文字位置、字号、描边、整体设计质量或完整无障碍合规。
- 单独的文件/任务选择窗口，包含最近完成文件、任务筛选、动作选择和确认步骤。
- Codex App Server 本机连接、任务绑定、通知和审批桥接。
- Windows 固定动作白名单、应用身份验证、紧急停止和隐私安全审计日志。
- NSIS 安装版、便携版、GitHub Releases 自动更新、SBOM、校验和与构建来源证明。
- 中文用户手册、Windows 控制手册、隐私政策、安全政策和签名政策。

### 不包含

- 任意文本输入、任意命令执行或通用 Windows UI 自动点击。
- 云端摄像头分析、账户系统、遥测或行为画像。
- macOS/Linux 安装包。
- 在没有有效 Authenticode 签名时宣称消除 SmartScreen 提示。

## 关键用户旅程

1. 首次运行：展开面板 → 用户主动开始监测 → 授予视频权限 → 完成四秒校准；只有主动打开麦克风时才单独授予音频权限。
2. 日常使用：在始终置顶的迷你摄像头 Dock 中观察实时画面与状态，鼠标移入或键盘聚焦时显示控制条，按需选择设备、声音、取景方式以及姿态/扫码/文档/文字/名片/隐私/背景/物体/对比模式 → 文件工具在完整面板中选择本机文件 → 保持手势 0.85 秒 → 看到动作结果 → 手势回到中性后才能再次触发。
3. Codex 操作：张开手掌 → 在独立窗口选择文件或任务 → 选择动作 → 确认执行。
4. 安全恢复：点击紧急停止 → 所有 Codex/Windows 桌面动作立即失败关闭 → 用户主动恢复。
5. 更新：安装版后台检查稳定版本 → 下载完成后提示 → 用户确认重启安装；便携版只提示手动更新。

## 发布决策

### 批量图片转换验收

- 同一图片分析入口接收 1–20 张 PNG/JPEG/WebP/BMP，单张最大 35 MB、合计最大 200 MB；用户可调整顺序和移除项目。
- 支持保留原尺寸或最长边 3200/2048/1600/1080/640 像素，不得放大小图；每个输出最长边不超过 8192 像素且不超过 2400 万像素。
- 支持 PNG/JPEG/WebP、40%–100% JPEG/WebP 品质、原名加编号或纯编号、安全前后缀与 0–999999 起始编号；Windows 保留名和非法字符必须安全化，三位顺序号避免同名覆盖。
- 任何设置或顺序变化都使首图预览失效；只有重新生成并滑动复核首图后才能逐张导出。每张处理完成后立即请求下载和释放临时 URL，不同时保留整批结果 Blob。
- 重新编码不得复制 EXIF/GPS 或覆盖源文件；JPEG 透明区域转白，格式编码不受支持时明确失败，并报告失败前已请求下载的数量。

### 表情动态面具验收

- 用户可从摄像头模式切换到“面具”，选择霓虹狐、机甲面罩或庆典假面；摄像头未启动时有明确启动入口。
- 面具必须随脸部位置、尺度和转动对齐，并对眨眼、抬眉、微笑与张嘴做可见响应；失去人脸、模型加载和模型错误都有文字状态。
- Face Landmarker 模型随包分发，只在本机按需加载；视频帧、关键点和 blendshape 不上传、不持久化，也不得宣称识别身份或真实情绪。

- 当前版本必须高于已发布版本，候选提交必须在受保护的 `main` 上通过 CI 与 Security。
- 缺少签名证书、精确签名主体或真实升级证据时，发布流程必须失败关闭。
- 产品代码就绪与公开商业发布是两个独立结论；只有全部发布门禁通过才能标记商业发布完成。
